바이브 코딩 — AI와 함께 만들며 배우기

🎯 학습목표
  • ‘바이브 코딩’ — AI에게 원하는 것을 말로 설명해 프로그램을 만들어 가는 방식을 이해한다.
  • GitHub Copilot·ChatGPT를 설계·작성·디버깅 도우미로 활용할 수 있다.
  • AI가 만든 코드를 직접 실행해 검증하고, 안 되면 오류를 붙여넣어 고치는 습관을 기른다.
📖 개념 및 설명

이번 장에서는 지금까지 배운 파이썬 문법으로 진짜 쓸 수 있는 프로그램을 만듭니다. 창(윈도우)이 있는 GUI 프로그램, 실행 파일(.exe)로 배포하기, 그리고 Flask 웹 서버까지 직접 만들어 봅니다.

바이브 코딩(Vibe Coding)은 "이런 걸 만들고 싶어"라고 말로 설명하면 AI가 코드를 만들어 주고, 우리는 그것을 실행·수정·이해하며 완성해 가는 개발 방식입니다. 문법을 다 외우지 못해도, 만들고 싶은 것이 분명하면 AI와 함께 만들 수 있습니다. 대신 내가 코드를 읽고 검증할 수 있어야 진짜 실력이 됩니다.

이럴 때 AI에게 물어보세요이렇게
무엇부터 만들지 막막할 때"tkinter로 버튼 하나 있는 창을 만드는 가장 짧은 코드 보여 줘"
기능을 추가하고 싶을 때"이 코드에 입력창과 검색 버튼을 추가해 줘"
오류가 날 때오류 전체를 붙여넣고 "왜 이런 오류가 나? 어떻게 고쳐?"
배포하고 싶을 때"이 파이썬 파일을 윈도우 exe로 만드는 방법 알려 줘"
⚠️ 학습 원칙 AI가 준 코드를 그대로 붙여넣기만 하면 실력이 늘지 않습니다. 한 줄씩 읽고 "이 줄이 무슨 일을 해?"라고 물으며, 반드시 직접 실행해 결과를 확인하세요.
🤖 좋은 프롬프트의 4가지 요소

🤖 원하는 프로그램을 얻는 질문법

만들고 싶은 것을 구체적으로 설명할수록 좋은 코드가 나옵니다.

  • ① 역할 — "너는 파이썬 GUI를 가르치는 선생님이야."
  • ② 상황/수준 — "나는 tkinter를 처음 쓰는 초보야."
  • ③ 원하는 것 — "입력창·버튼·결과 표시가 있는 창을 만들어 줘."
  • ④ 형식 — "각 줄에 주석을 달아 초보자용으로."
너는 파이썬 GUI를 가르치는 친절한 선생님이야. 나는 tkinter를 오늘 처음 쓰는 완전 초보야. '입력창 + 확인 버튼 + 결과 라벨'이 있는 아주 짧은 tkinter 창 코드를 만들어 주고, 각 줄이 무슨 일을 하는지 주석으로 설명해 줘.

GUI와 tkinter 기초

🎯 학습목표
  • GUI(그래픽 사용자 인터페이스)가 무엇인지 이해한다.
  • tkinter로 창(윈도우)을 만들고 제목·크기를 지정할 수 있다.
  • 라벨·버튼 같은 위젯을 창에 올릴 수 있다.
📖 개념 및 설명

GUI(Graphical User Interface)는 화면의 메뉴·버튼·입력창으로 사용자와 상호작용하는 프로그램입니다. 우리가 매일 쓰는 대부분의 앱이 GUI 프로그램이죠. 지금까지 만든 콘솔(검은 화면) 프로그램과 달리, 창이 뜨고 마우스로 클릭할 수 있습니다.

파이썬은 표준 라이브러리 tkinter로 GUI를 만듭니다. 별도 설치 없이 import tkinter로 바로 쓸 수 있어요. GUI 프로그램의 뼈대는 다음 표처럼 항상 같은 순서를 따릅니다.

단계코드설명
모듈 가져오기from tkinter import *tkinter의 모든 위젯 사용
윈도우 생성root = Tk()기본 창(루트 윈도우) 만들기
제목 지정root.title("제목")창 제목 표시줄 글자
위젯 구성Label(...), Button(...)라벨·버튼 등을 배치
실행(대기)root.mainloop()창을 띄우고 이벤트를 기다림
자주 쓰는 위젯 Label(글자 표시), Button(버튼), Entry(한 줄 입력상자), Text(여러 줄 출력상자), Frame(위젯을 담는 상자).
💡 예제

제목이 있는 창을 만들고, 라벨과 버튼을 올린 가장 기본적인 tkinter 프로그램입니다.

from tkinter import *

root = Tk()                       # 1. 기본 창 생성
root.title("첫 GUI 프로그램")         # 2. 창 제목
root.geometry("300x150")          # 3. 창 크기(너비x높이)

Label(root, text="안녕하세요! 👋").pack()   # 4. 라벨 배치
Button(root, text="확인").pack()          # 5. 버튼 배치

root.mainloop()                  # 6. 창 띄우고 대기
실행 결과 "첫 GUI 프로그램" 제목의 300x150 창이 뜨고, "안녕하세요! 👋" 라벨과 [확인] 버튼이 세로로 나타납니다.

⚠️ mainloop() 필수 root.mainloop()가 없으면 창이 떴다가 바로 사라집니다. GUI 코드의 맨 마지막 줄에 꼭 넣으세요.

🤖 "콘솔 프로그램과 뭐가 다른가요?"

GUI는 흐름이 콘솔과 달라 처음엔 낯섭니다. AI에게 개념을 비유로 물어보세요.

파이썬 tkinter의 mainloop()가 무슨 일을 하는지, 콘솔 프로그램(input/print)과 GUI 프로그램의 실행 흐름이 어떻게 다른지 초보자용으로 비유를 들어 설명해 줘.

위젯 종류가 궁금할 때:

tkinter에서 자주 쓰는 위젯 Label, Button, Entry, Text의 차이와 용도를 표로 정리하고, 각각을 하나씩 올린 짧은 예시 코드를 주석과 함께 보여 줘.

2

레이아웃 — pack()과 grid()

🎯 학습목표
  • 위젯을 화면에 배치하는 레이아웃 매니저의 역할을 이해한다.
  • pack()으로 위/아래/좌/우로 쌓아 배치할 수 있다.
  • grid()로 행·열 격자에 배치할 수 있다.
📖 개념 및 설명

위젯을 만들기만 해서는 화면에 안 나옵니다. 레이아웃 매니저로 "어디에 놓을지"를 정해야 보입니다. tkinter에는 pack(), grid(), place() 세 가지가 있고, 입문 단계에서는 pack과 grid를 씁니다.

방식특징주요 옵션
pack()위젯을 한 방향으로 쌓아서 배치(한 줄에 하나씩이 기본)side, fill, padx, pady
grid()표처럼 행(row)·열(column) 격자에 배치, 한 줄에 여러 개 가능row, column, columnspan
⚠️ 섞어 쓰지 마세요 같은 컨테이너(창·프레임) 안에서는 pack()과 grid()를 함께 쓰면 안 됩니다. 프로그램이 멈춘 것처럼 반응이 없어집니다. 하나를 골라 통일하세요.
💡 예제 — pack()

side 옵션으로 버튼을 좌우로 나란히 붙일 수 있습니다.

from tkinter import *

root = Tk()
root.geometry("260x80")

Button(root, text="왼쪽").pack(side="left", padx=5, pady=10)
Button(root, text="가운데").pack(side="left", padx=5)
Button(root, text="오른쪽").pack(side="left", padx=5)

root.mainloop()
실행 결과 [왼쪽] [가운데] [오른쪽] 버튼이 가로로 나란히 배치됩니다.

💡 예제 — grid()

간단한 로그인 폼처럼 라벨과 입력창을 격자에 배치합니다.

from tkinter import *

root = Tk()
root.title("로그인")

Label(root, text="아이디").grid(row=0, column=0, padx=5, pady=5)
Entry(root).grid(row=0, column=1)
Label(root, text="비밀번호").grid(row=1, column=0, padx=5, pady=5)
Entry(root, show="*").grid(row=1, column=1)
Button(root, text="로그인").grid(row=2, column=0, columnspan=2, pady=8)

root.mainloop()
실행 결과 아이디 / 비밀번호 라벨과 입력칸이 2행으로 정렬되고, 맨 아래 [로그인] 버튼이 두 칸에 걸쳐 배치됩니다.
columnspan 여러 열을 하나로 합쳐 넓게 배치합니다. 표의 '셀 병합'과 같은 개념입니다.

실습 2-1. 3x3 버튼판

grid()를 이용해 1~9 숫자가 적힌 버튼 9개를 3행 3열로 배치한 창을 만드세요.
정답 보기
from tkinter import *

root = Tk()
root.title("3x3 버튼판")

n = 1

버튼 클릭 이벤트

🎯 학습목표
  • 버튼을 눌렀을 때 실행할 함수(이벤트 핸들러)를 연결할 수 있다.
  • command 옵션에 함수를 괄호 없이 넘기는 이유를 안다.
  • 입력창(Entry)의 값을 읽어 라벨에 결과를 표시할 수 있다.
📖 개념 및 설명

버튼은 누를 때 무언가 실행되어야 의미가 있습니다. tkinter는 버튼의 command 옵션에 실행할 함수를 연결합니다.

⚠️ 괄호에 주의 command=click처럼 괄호 없이 함수 이름만 넘깁니다. command=click()처럼 괄호를 붙이면 버튼을 만드는 순간 함수가 실행되어 버립니다. 괄호를 빼야 클릭할 때 실행됩니다.

💡 예제 — 콘솔에 출력

버튼을 누르면 함수가 호출되어 콘솔에 글자를 출력합니다.

from tkinter import *

def click():                 # 버튼을 누르면 실행될 함수
    print("버튼이 눌렸습니다!")

root = Tk()
Button(root, text="확인", command=click).pack(padx=20, pady=20)
# command=click  → 괄호 없이! 클릭할 때 실행
root.mainloop()
실행 결과 (버튼을 누를 때마다 콘솔에) 버튼이 눌렸습니다!
💡 예제 — 입력값을 라벨에 출력

입력창에 쓴 이름을 읽어 인사말을 라벨에 표시합니다.

from tkinter import *

def greet():
    name = entry.get()             # 입력창의 글자 읽기
    result.config(text="안녕하세요, " + name + "님!")  # 라벨 글자 변경

root = Tk()
root.title("인사 프로그램")

entry = Entry(root)
entry.pack(padx=10, pady=10)
Button(root, text="인사하기", command=greet).pack()
result = Label(root, text="")      # 결과를 표시할 빈 라벨
result.pack(pady=10)

root.mainloop()
실행 결과 입력창에 "파이썬"을 쓰고 [인사하기]를 누르면 → 안녕하세요, 파이썬님!
핵심 3단계 ① entry.get()으로 입력값 읽기 → ② 결과 문자열 만들기 → ③ label.config(text=...)로 화면에 반영.
🤖 ChatGPT 활용

🤖 "command=click()은 왜 안 돼요?"

입문자가 가장 많이 하는 실수입니다. AI에게 이유를 물어 확실히 이해하세요.

tkinter 버튼에서 command=click 과 command=click() 의 차이가 뭐야? 괄호를 붙이면 왜 버튼을 누르기도 전에 함수가 실행되는지 초보자용으로 설명해 줘.
✏️ 실습문제

실습 3-1. 클릭 카운터

버튼을 누를 때마다 숫자가 1씩 올라가 라벨에 "클릭 횟수: N"으로 표시되는 프로그램을 만드세요.
정답 보기
from tkinter import *

count = 0
def add():
    global count
    count += 1
    label.config(text="클릭 횟수: " + str(count))

root = Tk()
label = Label(root, text="클릭 횟수: 0", font=("맑은 고딕", 14))
label.pack(pady=10)
Button(root, text="누르기", command=add).pack(pady=5)
root.mainloop()

🤖 AI 실습 3-2. 간단 계산기

숫자 두 개를 입력받아 [더하기] 버튼을 누르면 합을 라벨에 표시하는 프로그램을 ChatGPT와 함께 만들고, 문자열을 int()로 바꾸는 부분이 왜 필요한지 확인하세요.
예시 프롬프트 · 핵심 보기
tkinter로 입력창 2개와 [더하기] 버튼, 결과 라벨이 있는 창을 만들어 줘. 버튼을 누르면 두 입력값을 더해 라벨에 보여 주고, entry.get()이 문자열이라 int()로 바꿔야 하는 이유도 주석으로 설명해 줘.

entry.get()은 항상 문자열을 돌려주므로, 숫자 계산 전에 int()로 변환해야 합니다.

미니 프로젝트: 컴퓨터 용어 사전

🎯 학습목표
  • 딕셔너리 자료구조로 용어–뜻 데이터를 저장한다.
  • 입력창·버튼·출력상자를 조합해 검색 앱을 완성한다.
  • 검색 결과가 없을 때의 처리를 넣는다.
📖 개념 및 설명

지금까지 배운 딕셔너리와 tkinter를 합쳐 실제 쓸 수 있는 앱을 만듭니다. 용어와 뜻을 딕셔너리에 미리 저장해 두고, 단어를 입력해 [검색]을 누르면 출력상자에 뜻을 보여 줍니다. 없는 단어면 "사전에 없는 용어입니다."라고 안내합니다.

  • 데이터: {"CPU": "중앙처리장치...", ...} 딕셔너리
  • 입력: Entry에 단어 입력
  • 처리: dict.get(단어)로 뜻 찾기(없으면 안내문)
  • 출력: Text 상자에 결과 표시
💡 예제 — 컴퓨터용어사전.py 
from tkinter import *

# 1. 용어를 미리 정의 (딕셔너리 자료구조)
words = {
    "CPU": "중앙처리장치. 컴퓨터의 두뇌 역할을 한다.",
    "RAM": "주기억장치. 실행 중인 프로그램이 잠시 저장되는 공간.",
    "GUI": "그래픽 사용자 인터페이스. 버튼·창으로 조작하는 화면.",
    "IP": "인터넷에서 컴퓨터를 구분하는 주소.",
}

def search():
    word = entry.get().strip().upper()      # 입력값(공백 제거, 대문자)
    meaning = words.get(word, "사전에 없는 용어입니다..")  # 없으면 안내문
    output.delete("1.0", END)                # 이전 결과 지우기
    output.insert(END, word + " : " + meaning)  # 결과 출력

root = Tk()
root.title("컴퓨터 용어 사전")
root.geometry("360x220")

entry = Entry(root, width=20)
entry.pack(pady=8)
Button(root, text="검색", command=search).pack()
output = Text(root, width=40, height=6)
output.pack(pady=8)

root.mainloop()
실행 결과 "CPU" 입력 후 [검색] → CPU : 중앙처리장치. 컴퓨터의 두뇌 역할을 한다. "XYZ" 입력 후 [검색] → XYZ : 사전에 없는 용어입니다..
dict.get(키, 기본값) 키가 없으면 오류 대신 기본값을 돌려줍니다. 검색 앱에서 "없는 단어" 처리에 딱 맞습니다.

실행 파일(.exe) 배포 — PyInstaller

🎯 학습목표
  • 파이썬 파일(.py)을 윈도우 실행 파일(.exe)로 만드는 이유를 안다.
  • pyinstaller를 설치하고 배포 명령어를 사용할 수 있다.
  • 주요 옵션(--onefile, --windowed)의 뜻을 이해한다.
📖 개념 및 설명

내가 만든 프로그램을 다른 사람도 쓰게 하려면, 그 사람 컴퓨터에 파이썬이 없어도 실행돼야 합니다. PyInstaller는 .py 파일과 필요한 것들을 묶어 하나의 실행 파일(.exe)로 만들어 줍니다. 더블클릭만으로 실행되죠.

옵션뜻
--onefile여러 파일을 하나의 exe로 합침
--windowed실행 시 검은 콘솔 창을 숨김(GUI 프로그램용)
💡 예제 — 배포 절차

터미널(명령 프롬프트)에서 아래 순서로 실행합니다.

# 1. PyInstaller 설치 (최초 한 번)
pip install pyinstaller

# 2. 내 파이썬 파일이 있는 폴더로 이동
cd C:\pyworks\컴퓨터사전

# 3. exe로 변환 (GUI 프로그램이므로 --windowed)
pyinstaller --onefile --windowed 컴퓨터용어사전.py
실행 결과 같은 폴더에 dist 폴더가 생기고, 그 안에 컴퓨터용어사전.exe 파일이 만들어집니다. 이 exe를 더블클릭하면 파이썬 없이도 프로그램이 실행됩니다.
⚠️ 자주 겪는 일 exe 파일이 커지고(수십 MB) 처음 실행이 느릴 수 있습니다. 또 백신이 오탐할 수 있는데, 직접 만든 파일이면 정상입니다. build 폴더와 .spec 파일도 함께 생깁니다.
🤖 ChatGPT 활용

🤖 "exe로 만들 때 오류가 나요"

배포는 환경에 따라 오류가 잦습니다. 명령어와 오류를 그대로 붙여넣어 물어보세요.

pyinstaller --onefile --windowed 로 exe를 만들었는데 실행하면 창이 바로 꺼져. 원인으로 무엇이 있을 수 있고 어떻게 확인·해결하는지 초보자용으로 알려 줘.
✏️ 실습문제

실습 6-1. 내 앱을 exe로

4장에서 만든 컴퓨터 용어 사전을 --onefile --windowed 옵션으로 exe로 만들고, dist 폴더의 exe를 더블클릭해 실행되는지 확인하세요.

미니 프로젝트: 단위 변환기

🎯 학습목표
  • 입력 → 계산 → 출력의 흐름으로 실용 프로그램을 만든다.
  • 함수로 변환 로직을 나누어 재사용한다.
  • AI에게 요구사항을 설명해 프로그램을 함께 완성한다.
📖 개념 및 설명

길이·무게·온도처럼 단위를 바꿔 주는 프로그램을 만듭니다. 먼저 콘솔 버전으로 로직을 익히고, 원하면 AI와 함께 GUI로 확장합니다. 바이브 코딩은 "콘솔로 먼저 → 되면 화면 붙이기" 순서가 안전합니다.

💡 예제 — 단위 변환기(콘솔) 
def cm_to_inch(cm):
    return cm / 2.54          # 1인치 = 2.54cm

def kg_to_lb(kg):
    return kg * 2.20462       # 1kg = 2.20462파운드

cm = float(input("길이(cm): "))
print(round(cm_to_inch(cm), 2), "인치")

kg = float(input("무게(kg): "))
print(round(kg_to_lb(kg), 2), "파운드")
실행 결과 예시 길이(cm): 100 39.37 인치 무게(kg): 70 154.32 파운드
round(값, 자릿수) 소수점을 지정한 자리까지 반올림합니다. 변환 결과를 깔끔하게 보여 줄 때 유용합니다.

🤖 콘솔 → GUI로 확장하기

클라이언트와 서버

🎯 학습목표
  • 클라이언트와 서버가 각각 무슨 역할인지 이해한다.
  • 요청(request)과 응답(response)의 흐름을 안다.
  • 우리가 만들 웹 서버가 어디에 해당하는지 파악한다.
📖 개념 및 설명

웹은 클라이언트와 서버가 대화하는 구조입니다. 클라이언트가 "이거 주세요"라고 요청(Request)하면, 서버가 결과를 응답(Response)합니다.

  클라이언트                          서버
 (브라우저·앱)   ── 요청(Request) ──▶  (데이터·기능)
                ◀── 응답(Response) ──
구분역할예시

서버데이터·파일·웹페이지·기능을 제공. 항상 켜져 요청을 기다림웹 서버(네이버·구글), 게임 서버, DB 서버
이번 장에서는 파이썬 Flask로 웹 서버를 직접 만들고, 내 브라우저(클라이언트)로 접속해 봅니다.

Flask로 웹 서버 만들기

🎯 학습목표
  • Flask가 무엇인지 이해하고 설치할 수 있다.
  • 간단한 웹 서버를 만들어 브라우저로 접속한다.
  • @app.route로 여러 페이지(URL)를 연결(라우팅)한다.
📖 개념 및 설명

Flask(플라스크)는 파이썬으로 만든 마이크로 웹 프레임워크입니다. 몇 줄의 코드로 웹 서버를 만들고 웹 애플리케이션을 제작할 수 있어요. 가볍고 배우기 쉬워 입문용으로 좋습니다.

# Flask 설치 (최초 한 번)
pip install Flask
라우팅(routing) "어떤 주소(URL)로 들어오면 어떤 함수를 실행할지" 연결하는 것. @app.route("/")는 첫 페이지(홈)를 뜻합니다.
💡 예제 — 가장 간단한 웹 서버 (server01.py) 
from flask import Flask

app = Flask(__name__)          # Flask 앱 생성

@app.route("/")                  # 주소 "/"(홈)로 접속하면
def home():
    return "안녕하세요! 첫 Flask 서버입니다."

if __name__ == "__main__":
    app.run(debug=True)          # 서버 실행(5000번 포트)
실행 방법 & 결과 ① 터미널: python server01.py ② 브라우저 접속: http://127.0.0.1:5000 → 화면에 "안녕하세요! 첫 Flask 서버입니다." 출력
127.0.0.1:5000 127.0.0.1은 "내 컴퓨터"를 뜻하는 주소(localhost), 5000은 어떤 프로그램인지 구분하는 포트 번호입니다. localhost:5000도 동일합니다.
💡 예제 — 여러 페이지 라우팅

주소마다 다른 함수를 연결해 여러 페이지를 만듭니다.

from flask import Flask
app = Flask(__name__)

@app.route("/")
def home():
    return "홈페이지입니다."

@app.route("/about")            # /about 페이지
def about():
    return "소개 페이지입니다."

@app.route("/hello/<name>")     # 주소의 일부를 값으로 받기
def hello(name):
    return f"안녕하세요, {name}님!"

if __name__ == "__main__":
    app.run(debug=True)
브라우저 접속 결과 http://127.0.0.1:5000/ → 홈페이지입니다. http://127.0.0.1:5000/about → 소개 페이지입니다. http://127.0.0.1:5000/hello/파이썬 → 안녕하세요, 파이썬님!
🤖 ChatGPT 활용

🤖 "서버가 안 떠요 / 포트 오류가 나요"

flask 서버를 python server01.py로 실행했는데 'Address already in use' 또는 포트 5000 오류가 나. 원인과 해결 방법을 초보자용으로 알려 줘.
Flask에서 @app.route가 무슨 역할인지, 함수 위에 붙는 @데코레이터가 무엇인지 초보자용으로 비유를 들어 설명해 줘.

HTML과 CSS 기초

🎯 학습목표
  • HTML이 웹 문서의 뼈대를 만든다는 것을 이해한다.
  • 자주 쓰는 태그(h1~h6, p, img, a, ul/li)를 안다.
  • CSS로 디자인(색·크기·배치)을 입힐 수 있다.
📖 개념 및 설명

HTML(HyperText Markup Language)은 태그(tag)로 "어디가 제목이고 본문인지, 어디가 사진·링크인지" 표시하는 언어입니다. 웹 문서의 뼈대를 만들죠. 현재 버전은 HTML5입니다.

태그설명
<!DOCTYPE html>이 문서가 HTML5 문서임을 선언
<html>~</html>웹 문서의 시작과 끝
<head>~</head>브라우저가 해석할 정보(<meta>, <title>)
<body>~</body>화면에 실제로 보이는 내용
<h1>~<h6>제목. 1이 가장 크고 6이 가장 작음
<p>단락(paragraph). 앞뒤 줄바꿈이 있는 텍스트 덩어리
<img>이미지. src(경로), alt(대체글), width/height
<a>링크. <a href="주소">텍스트</a>
<ul> / <li>목록과 목록 안 항목
💡 예제 — 기본 HTML 문서 
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>내 첫 웹페이지</title>
</head>
<body>
  <h1>안녕하세요</h1>
  <p>이것은 <a href="https://python.org">파이썬</a> 페이지입니다.</p>
  <ul>
    <li>첫째</li>
    <li>둘째</li>
  </ul>
</body>
</html>
브라우저 표시 큰 제목 "안녕하세요", 그 아래 링크가 포함된 문장, 그리고 • 첫째 • 둘째 목록이 나타납니다.
📖 CSS — 디자인 입히기

CSS(Cascading Style Sheets)는 글자 색·크기, 이미지 위치, 배경 등 디자인 요소를 담당합니다. HTML이 뼈대라면 CSS는 옷과 화장입니다.

p {
    color: blue;          /* 글자색 */
    font-size: 20px;      /* 글자 크기 */
}
CSS 형식 태그 { 속성: 값; } — 스타일 속성을 세미콜론(;)으로 구분해 중괄호 { } 안에 나열합니다.

🤖 원하는 디자인을 말로 만들기

제목은 가운데 정렬에 진한 남색, 배경은 연한 회색, 본문 글자는 18px인 간단한 HTML+CSS 페이지를 만들어 줘. CSS가 어디에 적용됐는지 주석으로 설명해 줘.

종합 프로젝트: Flask 사진 갤러리

🎯 학습목표
  • Flask 웹 프로젝트의 폴더 구조(templates·static)를 이해한다.
  • render_template로 HTML 파일을 화면에 띄운다.
  • 여러 사진을 보여 주는 갤러리 페이지를 완성한다.
📖 개념 및 설명

지금까지 배운 Flask + HTML/CSS를 합쳐 사진 갤러리 웹사이트를 만듭니다. 규모가 커지면 코드를 파일로 나누는데, Flask는 정해진 폴더 구조를 씁니다.

위치역할
app.py서버 실행 파일(파이썬 코드)
templates/ 폴더HTML 파일들을 넣는 곳
static/ 폴더이미지·CSS 등 정적 파일을 넣는 곳
myweb/
├─ app.py
├─ templates/
│   ├─ index.html
│   └─ gallery.html
└─ static/
    ├─ style.css
    └─ 사진들(.jpg)
💡 예제 — app.py 
from flask import Flask, render_template
app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html")   # templates/index.html 표시

@app.route("/gallery")
def gallery():
    photos = ["cat.jpg", "dog.jpg", "bird.jpg"]  # 보여 줄 사진 목록
    return render_template("gallery.html", photos=photos)

if __name__ == "__main__":
    app.run(debug=True)
💡 예제 — templates/gallery.html

파이썬이 넘겨준 photos 목록을 반복문으로 그려 냅니다(Jinja 템플릿 문법).

<!DOCTYPE html>
<html>
<head><meta charset="UTF-8"><title>갤러리</title></head>
<body>
  <h1>사진 갤러리</h1>
  {% for photo in photos %}
    <img src="{{ url_for('static', filename=photo) }}" width="200">
  {% endfor %}
</body>
</html>
실행 결과 http://127.0.0.1:5000/gallery 접속 → static 폴더의 cat.jpg·dog.jpg·bird.jpg 사진이 가로로 나열됩니다.
{{ }} 와 {% %} Flask는 HTML 안에서 {{ 값 }}으로 파이썬 값을 넣고, {% for %}로 반복합니다. 이 문법을 템플릿(Jinja)이라 합니다.
🤖 ChatGPT 활용

🤖 갤러리를 예쁘게 & 기능 추가

Flask 사진 갤러리의 gallery.html에 CSS를 적용해 사진을 3열 격자로 예쁘게 배치하고, 각 사진에 둥근 모서리와 그림자를 넣어 줘. static/style.css로 분리해 줘.
내 static 폴더에 있는 이미지들을 자동으로 모두 갤러리에 보여 주려면 app.py를 어떻게 바꿔야 해? os 모듈로 파일 목록을 읽는 방법을 초보자용으로 알려 줘.
