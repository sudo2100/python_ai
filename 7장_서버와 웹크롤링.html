서버와 크롤링을 AI와 함께 다루기

🎯 학습목표
  • 서버·웹 개발과 크롤링을 배울 때 ChatGPT를 ‘코드를 만들고 오류를 진단해 주는’ 도우미로 활용할 수 있다.
  • “코드 짜 줘”보다 “이 태그를 어떻게 찾아? 이 선택자가 맞아?”처럼 구체적으로 묻는 법을 익힌다.
  • AI가 만든 크롤링 코드를 직접 실행해 실제 웹 데이터가 나오는지 확인하는 습관을 기른다.
📖 개념 및 설명

웹 크롤링은 사이트 구조에 따라 코드가 자주 바뀌는 분야입니다. 태그 이름이나 class가 달라지면 바로 결과가 안 나옵니다. 이럴 때 대상 페이지의 HTML 일부를 붙여넣고 “여기서 제목만 뽑는 선택자를 알려 줘”라고 물으면 ChatGPT가 정확한 select() 문을 만들어 줍니다.

이 교안은 항상 “AI에게 묻고 → 직접 실행하고 → 브라우저·출력으로 결과를 확인한다”는 흐름을 지킵니다.

이럴 때 물어보세요이렇게
선택자를 모를 때HTML 조각을 붙여넣고 “여기서 ○○를 뽑는 CSS 선택자 알려 줘”
오류가 날 때오류 메시지 전체를 붙여넣고 “왜 이런 오류가 나?”
결과가 비어 있을 때“find 결과가 None이야. 어떻게 확인하고 고쳐?”
⚠️ 학습 원칙 크롤링은 robots.txt와 저작권을 반드시 지켜야 합니다. AI가 준 코드라도 대상 사이트의 이용약관을 벗어나면 안 됩니다. 짧은 간격으로 반복 요청해 서버에 부담을 주지 않도록 주의하세요.

Flask 웹 서버 만들기

🎯 학습목표
  • Flask가 파이썬용 마이크로 웹 프레임워크임을 이해하고 설치할 수 있다.
  • @app.route()로 페이지 라우팅(URL 연결)을 만들 수 있다.
  • 서버를 실행해 http://127.0.0.1:5000으로 접속할 수 있다.
📖 Flask란?

플라스크(Flask)는 파이썬으로 제작된 마이크로 웹 프레임워크의 하나로, 웹 서버를 만들고 웹 애플리케이션을 제작할 수 있게 해 줍니다. 가볍고 배우기 쉬워 입문용으로 널리 쓰입니다.

설치 터미널에서 아래 명령으로 설치합니다. 
pip install Flask
공식 문서: flask.palletsprojects.com
💡 예제 — 가장 작은 웹 서버 (server01.py)

@app.route('/')는 “루트 경로(/)로 접속하면 이 함수를 실행하라”는 뜻입니다.

from flask import Flask

# Flask 애플리케이션 인스턴스(app 객체) 생성
app = Flask(__name__)

# 루트 경로에 대한 라우트 설정
@app.route('/')
def home():
    return "<h1>Hello, Flask!</h1>"

if __name__ == "__main__":
    # 디버그 모드로 서버 실행 (운영 시에는 debug=False)
    app.run(debug=True)
실행 방법 1. 터미널: python server01.py 2. 브라우저 접속: http://127.0.0.1:5000 * Running on http://127.0.0.1:5000 Press CTRL+C to quit
127.0.0.1 과 5000 127.0.0.1은 내 컴퓨터(localhost)에서 실행 중인 서버 주소이고, 5000은 포트 번호(어떤 프로그램인지 구분하는 번호)입니다. localhost:5000도 같은 뜻입니다.
💡 예제 — 페이지 라우팅 여러 개

경로마다 함수를 연결하면 여러 페이지를 가진 서버가 됩니다.

from flask import Flask

app = Flask(__name__)  # app 객체 생성

@app.route('/')            # http://127.0.0.1:5000/
def index():
    return "Hello~ Flask"

@app.route('/login')       # http://127.0.0.1:5000/login
def login():
    return "<h2><i>로그인</i> 페이지입니다.</h2>"

@app.route('/register')
def register():
    return "<h2>회원가입 페이지입니다.</h2>"

@app.route('/board/view')
def view():
    return "<h2>게시글 상세 페이지입니다.</h2>"
확인 /login → 로그인 페이지입니다. /board/view → 게시글 상세 페이지입니다.
반환값은 HTML return으로 돌려주는 문자열 안에 <h2> 같은 HTML 태그를 넣으면 브라우저가 그대로 해석해 보여줍니다.

HTML & CSS 기초

🎯 학습목표
  • HTML이 태그로 문서 구조를 표시하는 마크업 언어임을 이해한다.
  • 주요 태그(h1~h6, p, img, a, ul, li)의 쓰임을 안다.
  • CSS로 디자인(색·크기·글꼴)을 입히고, 선택자로 원하는 요소를 고를 수 있다.
📖 HTML이란?

HTML은 하이퍼텍스트를 마크업하는 언어(현재 버전 HTML5)입니다. 마크업이란 태그(tag)를 사용해 문서에서 어디가 제목이고 본문인지, 어디가 사진·링크인지 표시하는 것을 말합니다.

기본 태그설명
<!DOCTYPE html>현재 문서가 HTML5로 작성된 웹 문서라는 뜻(문서 유형 지정)
<html>~</html>웹 문서의 시작과 끝
<head>~</head>문서 해석에 필요한 정보. <meta>(문자 세트 등), <title>(제목 표시줄)
<body>~</body>실제 브라우저 화면에 나타날 내용
본문 태그설명
<h1>~<h6>제목(Headline). 1이 가장 크고 6이 가장 작음
<p>단락(paragraph). 앞뒤 줄바꿈이 있는 텍스트 덩어리
<img><img src="경로" alt="설명" width="너비"> — 이미지 삽입
<a><a href="주소">텍스트</a> — 클릭 시 다른 페이지로 이동
<ul> / <li>목록(ul)과 목록 안의 항목(li)
📖 CSS란?

HTML이 텍스트·이미지·표로 뼈대를 만든다면, CSS(Cascading Style Sheets)는 색상·크기·위치·배치 같은 디자인 요소를 담당합니다.

스타일은 태그 { 속성: 값; } 형식으로, 세미콜론(;)으로 구분해 중괄호 { } 안에 나열합니다.

p {
    color: blue;      /* 속성: 값; */
    font-size: 20px;
}
📖 선택자(Selector)

스타일을 적용할 대상을 선택자라고 합니다. 태그 하나가 될 수도 있고, id·class로 지정할 수도 있습니다.

선택자표기쓰임
태그 선택자p { }해당 태그를 쓴 모든 요소에 적용
id 선택자#이름 { }문서에서 한 번만 쓰는 요소에 지정
class 선택자.이름 { }문서에서 여러 번 반복할 스타일에 지정

아래 예제는 같은 <p>라도 class에 따라 다른 스타일이 적용되는 모습입니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>제품 목록</title>
    <style>
        h1 { color: blue; }
        p  { font-size: 18px; }
        .p1 { color: red; }
        .p2 { font-family: "궁서"; }
        .p3 { font-weight: bold; }
    </style>
</head>
<body>
    <h1>마늘</h1>
    <h2>마늘의 효능</h2>
    <p class="p1">마늘은 면역력 강화에 도움을 줍니다.</p>
    <p class="p2">마늘은 심혈관 건강에 좋습니다.</p>
    <p class="p3">마늘은 항산화 작용을 합니다.</p>
</body>
</html>

Flask 사진 서버 만들기

🎯 학습목표
  • render_template()로 HTML 파일을 화면에 띄울 수 있다.
  • static/photos 폴더의 이미지를 os.listdir()로 읽어 목록으로 넘길 수 있다.
  • 템플릿 문법 {{ }}·{% %}로 파이썬 값을 HTML에 반복 출력할 수 있다.
📖 프로젝트 폴더 구조

사진 서버는 아래처럼 파일을 배치합니다.

사진서버/
├── static/
│   ├── photos/
│   │   ├── photo1.jpg
│   │   ├── photo2.jpg
│   │   ├── photo3.jpg
│   │   └── photo4.jpg
│   └── main_pic.jpg
├── templates/
│   ├── gallery.html
│   └── index.html
└── app.py
💡 예제 — app.py

render_template()은 templates 폴더의 HTML을 찾아 보여줍니다. photos=photos로 파이썬 리스트를 HTML로 전달합니다.

from flask import Flask, render_template
import os

app = Flask(__name__)

@app.route("/")
def home():
    return render_template("index.html")

@app.route("/gallery")
def gallery():
    photos = os.listdir("static/photos")   # 폴더 안 파일 이름 목록
    return render_template("gallery.html", photos=photos)

if __name__ == "__main__":
    app.run(debug=True)
💡 예제 — index.html (대표 사진 1장)

{{ url_for('static', filename='...') }}는 static 폴더 안 파일 경로를 안전하게 만들어 줍니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>사진 보기</title>
</head>
<body>
    <h1>어느 봄날 카페에서...</h1>
    <img src="{{ url_for('static', filename='main_pic.jpg') }}" width="500">
</body>
</html>
💡 예제 — gallery.html (여러 장 반복 출력)

템플릿 언어의 제어문 {% %}와 출력문 {{ }}로 리스트를 반복해 이미지를 여러 개 출력합니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>사진 갤러리</title>
    <!-- CSS 스타일 추가 -->
    <style>
        h1 { color: blue; }
        img { width: 200px; margin: 10px; }
    </style>
</head>
<body>
    <h1>사진 갤러리</h1>
    {# 파이썬 템플릿 언어 - 제어문 {% %}, 출력문 {{ }} #}
    {% for photo in photos %}
        <img src="{{ url_for('static', filename='photos/' + photo) }}">
    {% endfor %}
</body>
</html>
실행 결과 — http://127.0.0.1:5000/gallery "사진 갤러리" 제목 아래에 photos 폴더의 사진 4장이 나란히 표시됨
{{ }} vs {% %} {{ 값 }}은 값을 화면에 출력할 때, {% 문법 %}은 for·if 같은 제어문을 쓸 때 사용합니다. {# #}은 템플릿 주석입니다.
🤖 ChatGPT 활용

🤖 템플릿 반복이 어려울 때

Flask 템플릿에서 {% for %}로 리스트의 이미지를 반복 출력하는 코드를 초보자용으로 설명해 줘. url_for('static', ...)가 왜 필요한지도 알려 줘.

Flask 템플릿 gallery.html에서 {% for photo in photos %} 반복문 안에서 이미지 아래에 그 파일 이름(photo)을 <p> 태그로 함께 출력하고 싶어. 코드를 고쳐 주고 설명해 줘.
{% for photo in photos %}
    <div>
        <img src="{{ url_for('static', filename='photos/' + photo) }}">
        <p>{{ photo }}</p>
    </div>
{% endfor %}

웹 크롤링과 requests

🎯 학습목표
  • 웹 크롤링(스크래핑)의 기본 흐름을 이해한다.
  • requests.get()으로 웹 페이지의 HTML을 가져오고 상태 코드를 확인할 수 있다.
  • robots.txt와 저작권 등 크롤링 시 지켜야 할 규칙을 안다.
📖 웹 크롤링이란?

웹 크롤링은 웹 페이지에서 자동으로 데이터를 수집하는 기술입니다. 업무 자동화나 데이터 분석에 아주 많이 쓰입니다. (예: 뉴스 제목 수집, 쇼핑몰 가격 모니터링, 공지사항 자동 수집, 환율·날씨 데이터 수집)

요청(Request)→ 웹 서버→ 응답(Response, HTML)→ 파싱(분석)→ 데이터 추출

주로 사용하는 라이브러리는 requests(요청)와 BeautifulSoup(bs4)(파싱)입니다.

📖 requests 모듈

requests는 파이썬용 HTTP 라이브러리로, HTTP 프로토콜을 이용해 웹 사이트로부터 데이터를 주고받습니다. URL 요청은 requests.get(url)로 합니다.

💡 예제 — 페이지 가져오기와 상태 코드

status_code가 200이면 정상, 404면 페이지 없음을 뜻합니다.

import requests

url = "https://www.python.org"
response = requests.get(url)

print(response)              # <Response [200]>
print(response.status_code)  # 200

html = response.text          # 응답받은 HTML 원문
print(html)
실행 결과 <Response [200]> 200 <!doctype html> ... (페이지 HTML 전체) ...
상태 코드 200 성공 · 404 없음 · 403 접근 금지 · 500 서버 오류. 없는 주소(예: python.org/3)를 요청하면 <Response [404]>가 나옵니다.
📖 로봇 배제 표준 (robots.txt)

로봇 배제 표준은 웹사이트에 로봇(크롤러)이 접근하는 것을 조절하기 위한 규약으로, robots.txt 파일에 규칙을 적습니다.

규칙의미
User-agent: *
Disallow: /		모든 로봇에게 루트(/) 이하 모든 문서 접근을 차단
User-agent: *
Allow: /		모든 로봇에게 모든 문서 접근을 허용
User-agent: *
Disallow: /temp/		특정 디렉터리(/temp/)만 접근 차단
⚠️ 지켜야 할 것 접근이 허용되더라도 서버에 무리가 갈 만큼 반복 요청하지 않아야 하며, 수집한 자료를 임의로 배포·변경하면 저작권 침해가 될 수 있습니다. 사이트의 주소/robots.txt로 규칙을 먼저 확인하세요.
💡 예제 — 여러 사이트의 robots.txt 확인 
import requests

urls = ["https://www.naver.com/", "https://www.python.org/"]
filename = "robots.txt"

for url in urls:
    url_path = url + filename
    print(url_path)
    response = requests.get(url_path)
    print(response)
실행 결과 https://www.naver.com/robots.txt <Response [200]> https://www.python.org/robots.txt <Response [200]>
🤖 ChatGPT 활용

🤖 이 사이트, 크롤링해도 될까?

웹 크롤링을 할 때 robots.txt는 무엇이고 어떻게 확인하는지, 그리고 크롤링 시 법적·윤리적으로 주의할 점을 초보자용으로 정리해 줘.
✏️ 실습문제

실습 5-1. 상태 코드 확인기

주소를 하나 정해 requests.get()으로 가져오고, "정상(200)"인지 아닌지 if문으로 출력해 보세요.
정답 보기
import requests

url = "https://www.python.org"
res = requests.get(url)

if res.status_code == 200:
    print("정상적으로 가져왔습니다!")
else:
    print("오류 코드:", res.status_code)

BeautifulSoup으로 파싱하기

🎯 학습목표
  • BeautifulSoup으로 HTML을 파싱(구조 분석)할 수 있다.
  • find()·find_all()로 태그와 class를 기준으로 요소를 찾을 수 있다.
  • select_one()·select()로 CSS 선택자를 이용해 요소를 찾을 수 있다.
📖 BeautifulSoup이란?

웹 서버로부터 받아온 HTML 소스코드는 그냥 긴 문자열입니다. 이 태그 구조를 해석하는 과정을 파싱(parsing)이라 하고, 이때 쓰는 라이브러리가 BeautifulSoup입니다.

설치와 사용 
pip install BeautifulSoup4
from bs4 import BeautifulSoup
📖 주요 검색 함수
함수설명
soup.find(태그)처음 나오는 태그 하나 찾기
soup.find_all(태그)해당 태그의 모든 요소를 리스트로 반환
soup.find(태그, attrs={'class':'값'})태그 + class 선택자로 찾기
soup.select_one("선택자")CSS 선택자로 첫 번째 요소 찾기
soup.select("선택자")CSS 선택자로 모든 요소 찾기(리스트)
선택자 표기 태그는 그대로, class는 .이름, id는 #이름, 자식 관계는 >로 씁니다. 예: div.m_service > ul > li.public
💡 예제 — find() / find_all()

attrs={'class': ...}로 특정 class를 가진 요소만 골라냅니다.

# find() : 조건에 맞는 첫 번째 요소 반환
first_li = soup.find('li', attrs={'class': 'public'})
print(first_li)
print(first_li.text)   # 태그를 뺀 글자만

# find_all() : 조건에 맞는 모든 요소 반환
div = soup.find('div', attrs={'class': 'm_service'})
all_li = div.find_all('li')

for li in all_li:
    print(li.text)

print(all_li[1].text)   # 두 번째 항목만
실행 결과 공공서비스예약 응답소(민원신고) 서울일자리 ... (이하 생략) ...
.text 요소에서 태그를 뺀 순수한 글자만 얻고 싶을 때 .text 또는 .get_text()를 씁니다.
💡 예제 — select_one() / select()

CSS 선택자를 그대로 쓸 수 있어 find보다 간결합니다.

# select_one() : CSS 선택자로 첫 번째 요소 반환
first_li = soup.select_one('div.m_service > ul > li.public')
print(first_li.text)

# select() : CSS 선택자로 모든 요소 반환
li = soup.select('div.m_service > ul > li')
for item in li:
    print(item.text)
실행 결과 공공서비스예약 응답소(민원신고) 서울일자리 ... (이하 생략) ...
🤖 ChatGPT 활용

🤖 선택자를 대신 만들어 달라고 하기

원하는 부분의 HTML 조각을 붙여넣고 선택자를 요청하면 정확한 코드를 얻을 수 있습니다.

다음 HTML에서 "공공서비스예약" 같은 메뉴 글자만 전부 뽑고 싶어. BeautifulSoup의 select()에 넣을 CSS 선택자를 알려 줘. <div class="m_service"><ul><li class="public"><a>공공서비스예약</a></li>...</ul></div>
✏️ 실습문제

실습 6-1. find와 select 비교

같은 요소를 find(태그, attrs=...)와 select_one(선택자) 두 가지 방법으로 각각 찾아 .text를 출력하고, 결과가 같은지 확인해 보세요.
정답 보기
# 방법 1 — find
a = soup.find('li', attrs={'class': 'public'})
print(a.text)

# 방법 2 — select_one
b = soup.select_one('li.public')
print(b.text)

print(a.text == b.text)   # True 이면 같은 결과

🎯 학습목표
  • 실제 사이트에서 F12(검사)로 태그·class를 확인하고 원하는 데이터를 뽑을 수 있다.
  • 서울시청·박물관·뉴스·환율 등 다양한 형태의 데이터를 수집해 본다.

💡 예제 2 — 국립중앙박물관 관람 정보

💡 예제 4 — 네이버 금융 환율 정보

홈페이지: 네이버 → 증권 → 시장지표 → 환전 고시 환율. F12로 div.market1 아래 span.blind(이름), span.value(가격)를 확인했습니다.

# 네이버 환율 정보
import requests
from bs4 import BeautifulSoup

url = "https://finance.naver.com/marketindex/"
response = requests.get(url)
html = BeautifulSoup(response.text, "html.parser")

# 환율 정보 리스트 전체
all_li = html.select("div.market1 ul li")

# 환율 종류 및 가격 출력
for li in all_li:
    exchange_name = li.select_one("span.blind").text.strip()
    exchange_price = li.select_one("span.value").text.strip()
    print(f"{exchange_name.split()[0]}: {exchange_price}")
실행 결과(예시) 미국: 1,467.80 일본: 925.44 유럽연합: 1,726.72 중국: 215.30
문자열 다듬기 .strip()은 앞뒤 공백 제거, .split()[0]은 공백으로 나눈 첫 단어만 사용합니다. (예: “미국 USD” → “미국”)

실습 7-1. 환율을 표로 정리

네이버 환율 예제를 응용해, 수집한 환율을 {'미국': '1,467.80', ...} 형태의 딕셔너리로 저장하고 출력해 보세요.

import requests
from bs4 import BeautifulSoup
