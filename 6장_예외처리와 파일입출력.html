예외와 파일을 AI와 함께 다루기

🎯 학습목표
  • 예외·파일을 배울 때 ChatGPT를 ‘문법을 알려 주고 오류를 진단해 주는’ 도우미로 활용할 수 있다.
  • “코드 짜 줘”보다 “이 오류가 왜 나?”, “이 모드가 맞아?”로 묻는 법을 익힌다.
  • AI가 만든 코드를 직접 실행해 파일 결과를 확인하는 습관을 기른다.
📖 개념 및 설명

파일 입출력은 오류가 자주 나는 분야입니다. 파일이 없거나, 모드가 틀렸거나, 인코딩이 안 맞아도 바로 에러가 납니다. 이럴 때 오류 메시지를 통째로 붙여넣고 물으면 ChatGPT가 원인을 빠르게 짚어 줍니다.

이 교안은 항상 “AI에게 묻고 → 직접 실행하고 → 파일에 실제로 반영됐는지 확인한다”는 흐름을 지킵니다.

이럴 때 물어보세요이렇게
오류가 날 때오류 전체를 붙여넣고 “왜 이런 오류가 나?”
모드가 헷갈릴 때“파일 열기 모드 r, w, a 차이 알려 줘”
한 줄씩 읽고 싶을 때“파일을 한 줄씩 읽어 처리하는 법 알려 줘”
⚠️ 학습 원칙 AI가 준 코드를 복붙만 하면 실력이 늘지 않습니다. 먼저 흐름(열기→읽기/쓰기→닫기)을 스스로 그려 본 뒤 “내 순서 맞아?”라고 물어보세요.

🤖 원하는 답을 얻는 질문법

  • ① 역할 — “너는 파이썬 파일·DB를 가르치는 선생님이야.”

1

예외 처리 — try ~ except

🎯 학습목표
  • 구문 오류와 예외(실행 오류)의 차이를 안다.
  • try ~ except로 예외를 처리할 수 있다.
  • 다중 예외와 raise를 사용할 수 있다.
📖 에러와 예외

오류는 크게 둘로 나뉩니다. 구문(Syntax) 오류는 문법이 틀려 실행 전에 IDE가 잡아 줍니다. 예외(Exception)는 문법은 맞지만 실행 중에 발생합니다. 예: 없는 파일 읽기, 리스트에 없는 요소 접근 등. 예외가 나면 프로그램이 중지·종료되므로 안전하게 처리해야 합니다.

예외 클래스발생 상황
ZeroDivisionError0으로 나눌 때
ValueError숫자 칸에 문자를 넣는 등 값이 부적절할 때
IndexError리스트 범위를 벗어난 인덱스 접근
KeyError딕셔너리에 없는 키 접근
FileNotFoundError없는 파일을 열려 할 때

이 예외들은 모두 Exception을 부모로 하는 계층 구조에 속합니다.

try:
    예외가 발생할 수 있는 코드
except 예외클래스:
    예외가 발생했을 때 실행할 코드
💡 예제 — 예외 종류별로 잡기

발생하는 예외 종류에 맞는 except로 각각 안내 메시지를 출력합니다. as e로 오류 내용도 함께 볼 수 있습니다.

try:
    print('20' + 20)
except TypeError as e:
    print("자료형 오류가 발생했습니다:", e)

try:
    print(10 / 0)
except ZeroDivisionError as e:
    print("0으로 나눌 수 없습니다:", e)

try:
    message = "Good Luck!" + friend
except NameError as e:
    print("변수가 정의되지 않았습니다:", e)
실행 결과 자료형 오류가 발생했습니다: can only concatenate str (not "int") to str 0으로 나눌 수 없습니다: division by zero 변수가 정의되지 않았습니다: name 'friend' is not defined
as e except 예외 as e로 받으면 e에 오류 메시지가 담겨, 무엇이 잘못됐는지 자세히 알 수 있습니다.
💡 예제 — 다중 try ~ except 
try:
    num = int(input("숫자 입력: "))
    print("10 ÷ 입력값 =", 10 / num)
except ValueError:
    print("숫자만 입력하세요!")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다!")
실행 예시 숫자 입력: 0 0으로 나눌 수 없습니다! 숫자 입력: abc 숫자만 입력하세요!
다중 except except를 여러 개 두면 예외 종류별로 다르게 대응할 수 있습니다. 모두 잡고 싶으면 except Exception as e:를 씁니다.
💡 예제 — raise로 예외 일으키기

raise는 내가 정한 조건에서 예외를 의도적으로 발생시킬 때 씁니다.

def set_age(age):
    if age < 0:
        raise ValueError("나이는 0 이상이어야 합니다")
    print("나이:", age)

try:
    set_age(-5)
except ValueError as e:
    print("오류:", e)
실행 결과 오류: 나이는 0 이상이어야 합니다

파일 입출력 — open

🎯 학습목표
  • 파일 입출력의 필요성과 흐름을 설명할 수 있다.
  • open의 모드(w·r·a)를 구분해 사용한다.
  • 파일에 쓰고 읽고 닫을 수 있다.
📖 개념 및 설명

프로그램이 종료되면 메모리의 데이터는 사라집니다. 계속 보관하려면 파일에 저장하고 필요할 때 읽어야 합니다. 파일 입출력은 열기 → 읽기/쓰기 → 닫기의 흐름입니다.

스트림(stream) 자료가 물 흐르듯 오가는 통로입니다. 파일에서 프로그램으로 읽어오면 입력 스트림(f.read()), 프로그램에서 파일로 내보내면 출력 스트림(f.write())입니다.
메서드 / 모드기능
open(파일, "w")쓰기 모드 (기존 내용 삭제)
open(파일, "r")읽기 모드
open(파일, "a")추가 쓰기 모드 (뒤에 붙임)
write() / read()내용 쓰기 / 읽기
close()파일 닫기
💡 예제 — 쓰기·읽기·추가 
# 쓰기 (w: 새로 만들거나 덮어쓰기)
f = open("file.txt", "w", encoding="utf-8")
f.write("안녕하세요\n")
f.write("파이썬 파일 입출력\n")
f.close()

# 추가 (a: 기존 내용 뒤에 붙임)
f = open("file.txt", "a", encoding="utf-8")
f.write("한 줄 더 추가\n")
f.close()

# 읽기 (r)
f = open("file.txt", "r", encoding="utf-8")
print(f.read())
f.close()

# 예외 처리 — 파일이 없을 때 안전하게
try:
    f = open("file.txt", "r", encoding="utf-8")
    print(f.read())
except FileNotFoundError:
    print("파일이 존재하지 않습니다.")
finally:
    f.close()
실행 결과 안녕하세요 파이썬 파일 입출력 한 줄 더 추가
⚠️ w 모드 주의 "w"로 열면 기존 내용이 모두 지워집니다. 이어 붙이려면 "a"(추가) 모드를 쓰세요. 또 close()를 잊으면 내용이 제대로 저장되지 않을 수 있습니다.

with ~ as 구문과 타자 게임

🎯 학습목표
  • with ~ as 구문의 장점을 설명할 수 있다.
  • close() 없이 안전하게 파일을 다룰 수 있다.
  • 파일과 random·time을 합쳐 타자 게임을 만든다.
📖 with ~ as 구문

with ~ as로 파일을 열면, 블록을 벗어날 때 에러 발생 여부와 관계없이 자동으로 close()가 호출됩니다. 코드가 간결하고 안전합니다.

with open(파일이름) as 파일객체:
    코드 블록   # 블록을 벗어나면 자동으로 close()
💡 예제 — 구구단 쓰기 · 리스트 쓰고 읽기 
# 구구단(2단) 파일에 쓰기
with open("gugu.txt", "w", encoding="utf-8") as f:
    for i in range(1, 10):
        f.write(f"2 x {i} = {2*i}\n")

# 리스트를 저장하고 다시 리스트로 읽기
fruits = ["사과", "바나나", "포도"]
with open("fruits.txt", "w", encoding="utf-8") as f:
    for fruit in fruits:
        f.write(fruit + "\n")

with open("fruits.txt", "r", encoding="utf-8") as f:
    lines = [line.strip() for line in f]
print(lines)
실행 결과 ['사과', '바나나', '포도']
🤖 ChatGPT 활용

🤖 with가 왜 안전한지 이해하기

파이썬에서 파일을 열 때 open + close 방식과 with 구문 방식을 비교해 줘. with가 왜 더 안전하고 편한지, 에러가 나도 왜 파일이 잘 닫히는지 초보자용으로 설명해 줘.
💡 예제 — 영어 타자 게임 (파일 + random + time)

파일에서 단어를 읽어와, 랜덤으로 문제를 내고 걸린 시간을 재는 게임입니다.

import random
import time

# 파일에서 단어 읽기
try:
    with open("typing_game/word.txt", "r") as f:
        # strip() 메서드를 사용하여 각 줄의 공백 제거
        word_list = [line.strip() for line in f]
except FileNotFoundError :
    print("파일이 존재하지 않습니다.")

print("[타자 게임] 준비되면 엔터!")
input()
start = time.time()            # 시작 시간

n = 1
while n <= 5:
    q = random.choice(word_list)
    print("제시어:", q)
    if input() == q:
        print("통과!")
        n += 1
    else:
        print("오타! 다시 도전!")

print(f"게임 종료! 걸린 시간: {time.time()-start:.2f}초")

바이너리 파일과 pickle

🎯 학습목표
  • 바이너리 파일이 무엇인지 안다.
  • rb·wb 모드로 이미지 등을 복사할 수 있다.
  • pickle로 객체를 그대로 저장·복원할 수 있다.
📖 바이너리 파일

바이너리 파일은 이미지·음성처럼 0과 1로 이루어진 파일입니다. 텍스트가 아니므로 바이트 모드로 열어야 합니다.

모드설명
wb바이너리 쓰기
rb바이너리 읽기
# 이미지 복사하기 (읽어서 다른 이름으로 쓰기)
with open("cat.jpg", "rb") as src:
    data = src.read()

with open("cat_copy.jpg", "wb") as dst:
    dst.write(data)

print("복사 완료, 크기:", len(data), "바이트")
📖 pickle 모듈

pickle은 리스트·딕셔너리 같은 객체의 형태를 그대로 유지하며 파일에 저장하고 불러오는 모듈입니다.

함수설명
pickle.dump(객체, 파일)객체 저장(쓰기)
pickle.load(파일)객체 불러오기(읽기)
import pickle

data = {"이름": "홍길동", "점수": [90, 85, 100]}

# 객체 저장 (바이너리 모드)
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

# 객체 그대로 복원
with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)

print(loaded)
print(type(loaded))   # 딕셔너리 그대로!

import pickle
nums = [10, 20, 30]
with open("nums.pkl", "wb") as f:
    pickle.dump(nums, f)
with open("nums.pkl", "rb") as f:
    print(sum(pickle.load(f)))
