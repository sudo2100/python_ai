AI 학습 가이드 — ChatGPT 200% 활용법

🎯 학습목표
  • ChatGPT를 '똑똑한 학습 파트너'로 활용하는 방법을 이해한다.
  • 원하는 답을 얻는 좋은 질문(프롬프트)을 작성할 수 있다.
  • AI가 준 코드와 설명을 스스로 검증하는 습관을 기른다.
📖 개념 및 설명

ChatGPT는 사람의 말로 질문하면 코드·설명·번역·요약을 돌려주는 대화형 AI입니다. 프로그래밍 입문자에게는 24시간 옆에 있는 개인 튜터와 같습니다. 개념이 이해되지 않거나, 코드가 왜 안 되는지 모를 때 즉시 물어볼 수 있습니다.

단, ChatGPT는 가끔 틀린 답(환각, hallucination)을 자신 있게 말하기도 합니다. 그래서 이 교안은 “AI에게 묻고 → 직접 실행해 확인하고 → 이해한다”는 흐름을 따릅니다. AI는 답을 대신 써 주는 도구가 아니라, 내가 더 빨리 배우도록 돕는 도구입니다.

이럴 때 ChatGPT를 쓰세요이렇게 물어보세요
개념이 어려울 때“초등학생도 알 수 있게 쉽게 설명해 줘”
코드에서 오류가 날 때오류 메시지 전체를 붙여넣고 “왜 이런 오류가 나?”
코드가 이해 안 될 때코드를 붙여넣고 “한 줄씩 주석으로 설명해 줘”
연습문제가 더 필요할 때“이 개념으로 초보자용 연습문제 3개 만들어 줘”
⚠️ 학습 원칙 정답 코드를 그대로 복사만 하면 실력이 늘지 않습니다. ChatGPT에게는 먼저 스스로 풀어본 뒤 “내 코드에서 뭐가 틀렸어?”, “더 좋은 방법이 있어?”라고 물어보세요.
🤖 좋은 프롬프트의 4가지 요소

🤖 원하는 답을 얻는 질문법

같은 질문도 구체적으로 물으면 훨씬 좋은 답이 나옵니다. 아래 4가지를 넣어 보세요.

  • ① 역할 — “너는 파이썬을 가르치는 친절한 선생님이야.”
  • ② 상황/수준 — “나는 프로그래밍을 오늘 처음 시작한 완전 초보야.”
  • ③ 원하는 것 — “변수 개념을 일상생활 비유로 설명해 줘.”
  • ④ 형식 — “3문장 이내로, 예시 코드도 하나 넣어서.”
너는 파이썬을 가르치는 친절한 선생님이야. 나는 오늘 처음 코딩을 시작한 완전 초보야. '변수'가 무엇인지 일상생활 비유로 3문장 이내로 설명하고, 간단한 예시 코드도 하나 보여 줘.

파이썬 소개와 설치

🎯 학습목표
  • 프로그래밍과 프로그램의 의미를 설명할 수 있다.
  • 인터프리터와 컴파일러의 차이를 구분할 수 있다.
  • 파이썬의 특징과 활용 분야를 이해한다.
  • 내 컴퓨터에 파이썬을 직접 설치할 수 있다.
📖 개념 및 설명

프로그래밍(Programming)이란 컴퓨터에게 원하는 작업을 시키기 위해 명령을 내리는 과정이고, 그 명령의 집합이자 결과물이 프로그램(Program)입니다. 우리가 쓰는 앱, 웹사이트, 게임이 모두 프로그램입니다.

사람이 쓴 코드는 컴퓨터가 바로 이해하지 못합니다. 컴퓨터가 아는 언어(기계어, 0과 1)로 바꿔주는 프로그램이 필요한데, 방식에 따라 두 가지로 나뉩니다.

구분동작 방식대표 언어
인터프리터코드를 한 줄씩 변환하며 실행Python, JavaScript
컴파일러전체 코드를 한 번에 변환한 뒤 실행C, C++, Java

파이썬은 1990년 네덜란드의 귀도 반 로섬(Guido van Rossum)이 만든 인터프리터 언어입니다. 이름은 그가 좋아하던 코미디 프로그램에서 따왔습니다.

파이썬의 특징

  • 사람이 생각하는 방식과 비슷해 문법이 간결하고 읽기 쉽다.
  • 오픈 소스라 무료이며 누구나 자유롭게 사용·확장할 수 있다.
  • 개발 속도가 빠르고, 다양한 라이브러리를 쓸 수 있다.
  • 플랫폼에 독립적(윈도우·맥·리눅스 모두 실행)이고 객체지향 언어이다.
파이썬으로 할 수 있는 일파이썬이 약한 분야
웹 개발(Django·Flask), 데이터 분석(Pandas·matplotlib), 머신러닝/딥러닝(TensorFlow·Keras), 업무 자동화, IoT(라즈베리파이) 운영체제 등 시스템 프로그래밍(주로 C), 안드로이드·아이폰 네이티브 앱
설치 방법 www.python.org → Downloads → 설치 파일 실행 → “Add python.exe to PATH” 체크 후 Install Now. PATH를 체크해야 어떤 경로에서든 python 명령을 쓸 수 있습니다.
💡 예제

설치가 잘 됐는지 확인하는 방법입니다. 명령 프롬프트(cmd)를 열고 아래를 입력합니다.

# 설치된 파이썬 버전 확인
python --version
Python 3.13.1 ← 이렇게 버전이 나오면 설치 성공

🤖 AI 실습 1-2. 오류 메시지 해결사

아래 오류가 났다고 가정하고, ChatGPT가 정확한 해결법을 주도록 프롬프트를 작성하세요. 실제 설치 중 오류가 났다면 그 메시지를 그대로 붙여넣어 물어보세요.

'python'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다.

핵심 원인은 설치할 때 “Add python.exe to PATH”를 체크하지 않은 것입니다. AI 답을 받은 뒤 실제로 PATH 설정을 확인하세요. — AI 답은 항상 직접 실행해 검증!

파이썬 IDLE와 기초 문법

🎯 학습목표
  • IDLE의 대화형 쉘과 에디터를 구분해 사용할 수 있다.
  • 코드를 파일(.py)로 저장하고 실행(F5)할 수 있다.
  • 주석과 들여쓰기 규칙을 지켜 코드를 작성할 수 있다.
📖 개념 및 설명

파이썬을 설치하면 IDLE이라는 기본 개발 도구가 함께 설치됩니다. IDLE은 두 가지 방식으로 사용합니다.

구분설명
대화형 쉘(Shell)>>> 기호는 입력을 기다린다는 뜻. 한 줄 입력하면 즉시 결과를 보여줌. 간단한 테스트에 좋다.
에디터(Editor)여러 줄 코드를 작성해 파일로 저장. File → New File → 코드 작성 → ex01.py로 저장 → Run → Run Module(F5)로 실행.
🎨 에디터 환경 설정 — 글꼴·화면 색상 바꾸기 IDLE 상단 메뉴에서 Options → Configure IDLE → Settings 로 들어가면 편집 환경을 내 취향에 맞게 바꿀 수 있습니다.
  • 글꼴 변경 — Fonts 탭에서 글꼴을 Consolas, 크기(Size)를 17로 설정합니다.
  • 화면 색상 변경 — Highlights 탭에서 테마를 IDLE Dark로 선택하면 눈이 편한 어두운 배경으로 바뀝니다.

기초 문법 3가지

  • 자료형을 미리 선언하지 않는다. n = 10, msg = 'hello'처럼 값을 넣으면 타입이 자동 결정됩니다.
  • 주석(comment)은 코드 설명용 메모로 실행되지 않습니다. 한 줄은 #, 여러 줄은 따옴표 3개("""~""")를 씁니다.
  • 들여쓰기(indent)로 코드 블록을 구분합니다. 보통 스페이스 4칸을 쓰며, 들여쓰기가 어긋나면 오류가 납니다.
⚠️ 자주 하는 실수 파이썬은 들여쓰기가 문법입니다. 한 블록 안에서 4칸과 2칸을 섞으면 IndentationError가 발생합니다.
💡 예제 
# 한 줄 주석: 화면에 인사말을 출력한다
print("Hello, Python!")

"""
여러 줄 주석
이 안의 내용은 실행되지 않습니다.
"""
print("파이썬 공부 시작!")
실행 결과 Hello, Python! 파이썬 공부 시작!
🤖 ChatGPT 활용

🤖 코드를 붙여넣고 "설명해 줘"

남이 쓴 코드나 예제를 만나면, ChatGPT에게 붙여넣고 한 줄씩 설명을 요청하면 이해가 빨라집니다.

아래 파이썬 코드를 초보자용으로 한 줄씩 주석을 달아 설명해 줘. 특히 따옴표 3개(""")가 무슨 역할인지 알려 줘. print("Hello, Python!") """여러 줄 주석""" print("파이썬 공부 시작!")

변수(Variable)

🎯 학습목표
  • 변수의 개념과 역할을 메모리 관점에서 이해한다.
  • 변수를 선언하고 값을 저장·변경할 수 있다.
  • 올바른 변수 이름 규칙을 지켜 이름을 지을 수 있다.
📖 개념 및 설명

변수(variable)는 프로그램에서 사용할 데이터를 저장하는 메모리 공간입니다. 값이 바뀔 수 있어서 ‘변하는 수’라는 뜻의 변수라 부릅니다. 데이터를 담는 이름표가 붙은 상자라고 생각하면 쉽습니다.

변수 선언과 초기화

변수를 처음 만들면서 값을 넣는 것을 선언과 초기화라고 합니다. 파이썬은 자료형을 미리 쓰지 않고 변수이름 = 값 형태로 선언과 동시에 값을 넣습니다. 아래에서는 level이라는 이름표가 붙은 상자에 5가, id 상자에 "cloud"가 담깁니다.

level = 5
id = "cloud"

변수 이름 짓기 규칙

  • 영문·숫자·밑줄(_)·한글을 조합할 수 있다. (실무에서는 영문 권장)
  • 숫자로 시작할 수 없고, 이름 중간에 공백이 있으면 안 된다.
  • 대문자와 소문자를 구분한다. (age와 Age는 다른 변수)
  • 예약어(if, for, while 등)는 이름으로 쓸 수 없다.
💡 예제 
name = "홍길동"
age = 20

print(name, "님의 나이는", age, "살입니다.")

age = 21          # 변수 값은 언제든 바꿀 수 있다
print("내년에는", age, "살이 됩니다.")
실행 결과 홍길동 님의 나이는 20 살입니다. 내년에는 21 살이 됩니다.
🤖 ChatGPT 활용

🤖 변수 이름, AI에게 추천받기

좋은 변수 이름은 코드를 읽기 쉽게 만듭니다. 무엇을 담을지 설명하면 AI가 관례에 맞는 이름을 제안합니다.

자료형(Data Type)

🎯 학습목표
  • 자료형이 무엇이고 왜 필요한지 설명할 수 있다.
  • 정수·실수·문자열·논리형을 구분할 수 있다.
  • type()으로 값의 자료형을 확인할 수 있다.
📖 개념 및 설명

자료형(Data Type)은 데이터의 종류에 따라 메모리 공간을 알맞게 정해 주는 것입니다. 파이썬은 값을 넣으면 자료형을 자동으로 판단하므로 따로 표기하지 않습니다.

분류자료형설명예
정수int소수점이 없는 수-2, 0, 100
실수float소수점이 있는 수(부동소수점)-3.5, 0.0, 1.25
문자열str따옴표로 감싼 문자·문장"a", 'hello', "비"
논리형bool참/거짓 (값은 True, False 둘뿐)True, False
type() 함수 값이나 변수의 자료형이 궁금할 땐 type(값)으로 확인합니다.
💡 예제 
num = 10
pi = 3.14
name = "파이썬"
is_fun = True

print(type(num))
print(type(pi))
print(type(name))
print(type(is_fun))
실행 결과 <class 'int'> <class 'float'> <class 'str'> <class 'bool'>
🤖 ChatGPT 활용

🤖 헷갈리는 자료형, 표로 정리받기

자료형이 헷갈릴 때 AI에게 표나 예시로 정리해 달라고 하면 한눈에 들어옵니다.

파이썬의 int, float, str, bool 자료형을 표로 정리해 줘. 각 자료형의 예시 값 3개와, 초보자가 자주 헷갈리는 부분도 한 줄씩 적어 줘.

실행 결과를 미리 예측 연습할 때:

print(type(3.0)) 의 결과를 먼저 알려 주지 말고, 내가 답을 맞혀볼 테니 힌트만 줘. 내가 답하면 맞는지 알려 줘.
✏️ 실습문제

2026, 98.6, "010-1234", False
정답 보기

2026 → int,   98.6 → float,   "010-1234" → str,   False → bool

→ <class 'int'> <class 'float'> <class 'str'> <class 'bool'>
주의 "010-1234"는 숫자처럼 보여도 따옴표로 감쌌으니 문자열(str)입니다.

예시 프롬프트 보기

AI를 출제자로 활용하면 무한히 연습할 수 있습니다. 채점 후 type()으로 최종 검증하세요.

컴퓨터의 데이터 표현

🎯 학습목표
  • 비트와 2진수의 개념을 이해한다.
  • 10진수를 2진수로 바꿀 수 있다.
  • 아스키 코드와 유니코드의 차이를 설명할 수 있다.
📖 개념 및 설명

컴퓨터는 오직 0과 1로만 데이터를 저장합니다(0=신호 꺼짐, 1=신호 켜짐). 이 0 또는 1 하나를 담는 최소 단위가 비트(bit)입니다. 비트가 늘어날수록 표현할 수 있는 수의 범위가 2배씩 커집니다.

비트 수표현 범위(10진수)경우의 수
1 bit0 ~ 12¹ = 2가지
2 bit0 ~ 32² = 4가지
3 bit0 ~ 72³ = 8가지
8 bit(1바이트)0 ~ 2552⁸ = 256가지

10진수 → 2진수 변환 원리 — 각 자리는 8·4·2·1 처럼 2의 거듭제곱 값을 가집니다.

  8  4  2  1
  1  0  1  0   →  8 + 2 = 10
# 즉 10(10진수) = 1010(2진수)

문자를 저장하는 방법 — 문자도 숫자(코드값)로 바꿔 저장합니다.

코드설명
아스키 코드(ASCII)영문·숫자·기호 등 128개 문자를 7비트로 표현. 1963년 미국 표준. 예: 'A'=65, 'a'=97, '0'=48
유니코드(Unicode)전 세계 문자를 일관되게 처리하는 국제 표준. 한글·중국어 등 아스키로 표현 못 하는 문자까지 지원.
파이썬에서 코드값 확인 문자→코드값은 ord(), 코드값→문자는 chr()로 변환합니다.
💡 예제 
print(bin(10))     # 10진수를 2진수 문자열로
print(ord("A"))     # 문자 A의 아스키 코드값
print(chr(97))     # 코드값 97에 해당하는 문자
실행 결과 0b1010 65 a

0b는 2진수라는 표시입니다.

🤖 ChatGPT 활용

🤖 진수 변환, 원리까지 물어보기

답만 얻지 말고 과정을 물어보면 스스로 계산하는 힘이 생깁니다.

10진수 45를 2진수로 바꾸는 과정을 8·4·2·1처럼 자릿값을 이용해 초보자도 이해할 수 있게 단계별로 보여 줘. 답만 말하지 말고 왜 그렇게 되는지 설명해 줘.

아스키/유니코드 차이가 헷갈릴 때:

아스키 코드와 유니코드의 차이를, 한글이 왜 아스키로 표현이 안 되는지 예를 들어 쉽게 설명해 줘.
✏️ 실습문제

정답 보기

8·4·2·1 자리로 나누면 8 + 4 + 1 = 13 → 1101

자료형 변환(형 변환)

🎯 학습목표
  • 형 변환이 필요한 상황을 이해한다.
  • int(), float(), str()로 자료형을 바꿀 수 있다.
  • 숫자 문자열과 숫자를 구분하고 올바르게 계산할 수 있다.
📖 개념 및 설명

형 변환(Type Conversion)은 값의 자료형을 다른 자료형으로 바꾸는 것입니다. 특히 input()으로 받은 값은 항상 문자열(str)이라, 계산하려면 숫자로 바꿔야 합니다.

함수역할예
int(x)정수로 변환int("10") → 10
float(x)실수로 변환float("3.5") → 3.5
str(x)문자열로 변환str(10) → "10"
⚠️ 문자열 + 숫자 오류 "10" + 5 처럼 문자열과 숫자를 더하면 TypeError가 납니다. 형을 맞춰야 합니다.
💡 예제 
a = "10"          # 문자열
b = 5             # 정수

print(int(a) + b)   # 문자 "10"을 숫자 10으로 바꿔 더함

print("나이: " + str(20))   # 숫자 20을 문자로 바꿔 연결
실행 결과 15 나이: 20
🤖 ChatGPT 활용

🤖 TypeError, 오류 메시지째로 물어보기

형 변환 실수는 TypeError를 자주 냅니다. 오류 전체를 붙여넣고 물으면 원인과 수정법을 짚어 줍니다.

파이썬에서 아래 코드를 실행하니 TypeError: can only concatenate str (not "int") to str 오류가 나. 왜 그런지 초보자용으로 설명하고, 두 가지 해결 방법을 보여 줘. age = "20" print("나이는 " + age + 1)
✏️ 실습문제

실습 6-1. 문자열 숫자 더하기

변수 x = "7", y = "3"이 있습니다. 두 값을 더한 값 10이 나오도록 형 변환하여 출력하세요.
정답 보기
x = "7"
y = "3"
print(int(x) + int(y))   # 10
10

만약 변환 없이 x + y를 하면 문자열이 이어져 "73"이 됩니다.

🤖 AI 실습 6-2. 일부러 오류 내고 고치기

일부러 print("7" + 3)처럼 오류가 나는 코드를 실행해 보세요. 나타난 오류 메시지를 그대로 ChatGPT에 붙여넣어 원인과 수정법을 받고, 고친 코드를 실행해 결과를 확인하세요.
예시 흐름 보기

① 오류 재현

print("7" + 3)
TypeError: can only concatenate str (not "int") to str

② 오류 메시지를 AI에 붙여넣고 물어보기 → ③ 고친 코드 실행

print(int("7") + 3)   # 10

오류는 실패가 아니라 가장 좋은 학습 재료입니다. AI와 함께라면 두렵지 않아요.

문자열 다루기

🎯 학습목표
  • 따옴표를 상황에 맞게 사용할 수 있다.
  • 여러 줄 문자열을 출력할 수 있다.
  • 이스케이프 문자로 줄바꿈·탭 등을 표현할 수 있다.
📖 개념 및 설명

문자열은 작은따옴표(') 또는 큰따옴표(")로 감쌉니다. 문자열 안에 따옴표를 넣을 땐 바깥과 겹치지 않게 씁니다. 여러 줄을 그대로 출력하려면 따옴표 3개("""~""")로 감쌉니다.

이스케이프 문자 — 역슬래시(\)로 시작하는 특수 표현입니다.

코드의미
\n줄바꿈
\t탭(문자열 간격)
\' , \"따옴표 자체를 문자로 표시
💡 예제 
print('그는 "안녕"이라고 말했다.')   # 겹치지 않게 따옴표 사용
print("이름\t나이")              # 탭으로 간격
print("첫째 줄\n둘째 줄")          # 줄바꿈

print("""여러 줄을
그대로 출력할 때는
따옴표 3개를 씁니다.""")
실행 결과 그는 "안녕"이라고 말했다. 이름 나이 첫째 줄 둘째 줄 여러 줄을 그대로 출력할 때는 따옴표 3개를 씁니다.

🤖 원하는 출력 모양 → 코드로 받기

파이썬 print() 한 줄로 아래처럼 출력하고 싶어. 이스케이프 문자를 써서 코드를 만들어 주고, 각 기호가 무슨 역할인지 설명해 줘. 이름: 홍길동 나이: 20

8

연산자(Operator)

🎯 학습목표
  • 항과 연산자의 개념을 이해한다.
  • 산술·대입·복합대입·비교·논리 연산자를 사용할 수 있다.
  • 몫(//), 나머지(%), 거듭제곱(**)을 구분해 계산할 수 있다.
📖 개념 및 설명

연산에 쓰이는 값을 항(operand), 연산에 쓰이는 기호를 연산자(operator)라고 합니다. 예를 들어 3 + 7에서 3과 7은 항, +는 연산자입니다.

① 대입 연산자 — 오른쪽 값을 왼쪽 변수에 넣습니다. 계산은 오른쪽 먼저, 대입은 나중입니다. total = num1 + num2는 덧셈을 먼저 하고 그 결과를 total에 넣습니다.

② 산술 연산자

연산자의미예 (n=7)결과
+  -  *  /더하기·빼기·곱하기·나누기7 / 23.5
//몫(나눗셈의 정수 부분)7 // 23
%나머지7 % 21
**거듭제곱7 ** 249

③ 복합 대입 연산자 — 계산과 대입을 한 번에. val += 10은 val = val + 10과 같습니다. (-=, *=, /=, %= 동일)

④ 비교 연산자 — 결과는 항상 True/False.

연산자의미예결과
<  >  <=  >=대소 비교9 < 10True
==같다9 == 10False
!=같지 않다9 != 10True

⑤ 논리 연산자

연산자규칙
x and y둘 다 참이면 참, 나머지는 거짓
x or y둘 중 하나만 참이어도 참
not x참이면 거짓, 거짓이면 참
문자열 연산 +는 문자열을 이어 붙이고("안녕"+"하세요" → 안녕하세요), *는 반복합니다("-"*10 → 대시 10개).
💡 예제 
a = 7
b = 2

print(a + b, a - b, a * b)   # 9 5 14
print(a / b)                # 3.5  (나누기)
print(a // b, a % b)         # 3 1  (몫, 나머지)
print(a ** b)               # 49   (거듭제곱)

count = 10
count += 5               # count = count + 5
print(count)               # 15

print(a > b and b > 0)     # True
print("안녕" + "하세요")      # 안녕하세요
print("=" * 10)             # ==========
실행 결과 9 5 14 3.5 3 1 49 15 True 안녕하세요 ==========

파이썬의 몫(//)과 나머지(%) 연산자가 실생활에서 어디에 쓰이는지 예시 3개를 들어 설명해 줘. 각 예시마다 짧은 파이썬 코드도 보여 줘.

실습 8-1. 몫과 나머지 계산하기

빵 30개를 4명이 나눠 가질 때, 한 사람이 몇 개씩 갖고(몫) 몇 개가 남는지(나머지)를 계산해 출력하세요.
정답 보기
bread = 30
people = 4
print("한 사람 몫:", bread // people, "개")
print("남는 빵:", bread % people, "개")
한 사람 몫: 7 개 남는 빵: 2 개

실습 8-2. 두 변수 값 교환하기

x = 1, y = 2일 때 두 변수의 값을 서로 바꿔 x=2, y=1이 되게 하세요. (힌트: 파이썬은 x, y = y, x처럼 한 줄로 교환 가능)
정답 보기
x = 1
y = 2
x, y = y, x        # 구조 분해 할당으로 값 교환
print(x, y)         # 2 1
2 1

다음 식의 결과(True/False)를 먼저 예측한 뒤 실행해 확인하세요.
① 5 > 3 and 2 > 4   ② 5 > 3 or 2 > 4   ③ not (1 == 1)
정답 보기

① False (뒤 조건이 거짓)   ② True (하나만 참이어도 참)   ③ False (참을 뒤집음)

9

입력 처리 input()

🎯 학습목표
  • input()으로 사용자 입력을 받을 수 있다.
  • 입력값이 문자열임을 이해하고 형 변환할 수 있다.
  • 입력 → 계산 → 출력 흐름의 프로그램을 만들 수 있다.
📖 개념 및 설명

input()은 사용자가 키보드로 입력한 값을 받아오는 함수입니다. 괄호 안에 안내 문구(프롬프트)를 넣을 수 있습니다.

⚠️ 핵심 주의 input()이 돌려주는 값은 항상 문자열(str)입니다. 숫자로 계산하려면 int()나 float()로 반드시 변환해야 합니다.
name = input("이름을 입력하세요: ")      # 문자열 그대로 사용
age = int(input("나이를 입력하세요: "))  # 숫자로 변환
💡 예제

나이를 입력받아 내년 나이를 계산하는 프로그램입니다.

name = input("이름: ")
age = int(input("나이: "))     # 문자열 → 정수 변환

print(name + "님, 내년에는 " + str(age + 1) + "살이 됩니다.")
실행 예시 (밑줄은 사용자 입력) 이름: 홍길동 나이: 20 홍길동님, 내년에는 21살이 됩니다.
🤖 ChatGPT 활용

🤖 AI와 함께 미니 프로그램 만들기

이제 배운 것을 모아 작은 프로그램을 만들 차례입니다. 만들고 싶은 것을 말로 설명하면 AI가 뼈대를 잡아 줍니다.

파이썬 초보야. input()으로 키(cm)와 몸무게(kg)를 입력받아 BMI를 계산해 출력하는 프로그램을 만들어 줘. 입력값을 왜 형 변환해야 하는지 주석으로 설명도 넣어 줘.
⚠️ 반드시 검증 AI가 준 코드는 그대로 믿지 말고 직접 실행하세요. 원하는 값이 나오는지, input 값을 형 변환했는지 확인하고, 이해 안 되는 줄은 “이 줄 설명해 줘”라고 다시 물어보세요.
✏️ 실습문제

실습 9-1. 사각형 넓이 계산기

가로와 세로 길이를 입력받아 사각형의 넓이(가로 × 세로)를 계산해 출력하는 프로그램을 작성하세요.
실행 결과 예시 가로: 5 세로: 3 사각형의 넓이는 15 입니다.
정답 보기
width = int(input("가로: "))
height = int(input("세로: "))
area = width * height
print("사각형의 넓이는", area, "입니다.")

실습 9-2. 나이 계산 프로그램

태어난 연도를 입력받아, 올해(2026년) 기준 나이를 계산해 출력하세요. (나이 = 2026 − 태어난 연도)
정답 보기
birth = int(input("태어난 연도: "))
age = 2026 - birth
print("당신의 나이는", age, "살입니다.")
태어난 연도: 2000 당신의 나이는 26 살입니다.

🤖 AI 실습 9-3. 나만의 계산기 기획 → AI로 완성

1장에서 배운 변수 · 자료형 · 형 변환 · 연산자 · input()을 모두 쓰는 나만의 미니 계산기를 정하세요(예: 팁 계산기, 할인가 계산기, 용돈 나누기). ChatGPT에 아이디어를 설명해 코드를 받은 뒤, 직접 실행·검증하고 이해 안 되는 줄은 추가 질문하세요.
예시 프롬프트 · 검증 체크리스트 보기
파이썬 초보야. 음식값과 팁 비율(%)을 input()으로 입력받아, 팁 금액과 최종 결제 금액을 계산해 출력하는 프로그램을 만들어 줘. 변수 이름은 알아보기 쉽게 짓고, 형 변환이 필요한 부분은 주석으로 이유를 설명해 줘.

실행 후 스스로 점검(검증 체크리스트)

  • 입력값을 int()/float()로 형 변환했는가?
  • 계산 결과가 손으로 계산한 값과 같은가?
  • 모든 줄을 내가 설명할 수 있는가? (못 하면 AI에 “이 줄 설명해 줘”)
