함수를 AI와 함께 설계·검증하기

🎯 학습목표
  • 함수를 배울 때 ChatGPT를 설계·리팩터링 도우미로 활용할 수 있다.
  • “코드를 만들어 줘”보다 “이 함수를 개선해 줘 / 왜 이렇게 동작해?”로 묻는 법을 익힌다.
  • AI가 만든 함수를 여러 입력으로 직접 실행해 검증하는 습관을 기른다.
📖 개념 및 설명

1·2장에서 배운 변수·제어문·자료구조에 이어, 3장에서는 반복되는 코드를 함수로 묶어 재사용합니다. 함수는 “입력을 받아 → 처리하고 → 결과를 돌려주는” 작은 부품입니다. 이 단계부터는 코드를 구조적으로 설계하는 감각이 중요해집니다.

이때 ChatGPT는 훌륭한 짝 프로그래머가 됩니다. 반복되는 코드를 함수로 묶어 달라고 하거나(리팩터링), 내가 만든 함수가 왜 원하는 값을 안 돌려주는지 물어볼 수 있습니다. 다만 AI 함수는 특정 입력에서만 맞고 경계에서 틀릴 때가 있으므로, 이 교안은 항상 “AI에게 묻고 → 여러 입력으로 실행해 확인하고 → 이해한다”는 흐름을 지킵니다.

3장에서 이럴 때 물어보세요이렇게
반복 코드를 정리하고 싶을 때코드를 붙여넣고 “이걸 함수로 묶어 줘”
함수가 값을 안 돌려줄 때“이 함수가 왜 None을 반환해?”
매개변수 설계가 고민될 때“이 함수의 매개변수를 어떻게 잡는 게 좋아?”
연습이 더 필요할 때“함수 만들기 연습문제 3개 내 줘(정답은 숨기고)”
⚠️ 학습 원칙 AI가 만든 함수를 복붙만 하면 설계력이 늘지 않습니다. 먼저 스스로 함수를 짜 본 뒤 “내 함수 어디가 어색해?”, “더 간결하게 만들 수 있어?”라고 물어보세요.

1

함수의 개념과 정의

🎯 학습목표
  • 함수가 왜 필요한지(재사용·모듈화·가독성) 설명할 수 있다.
  • def로 함수를 정의하고 호출할 수 있다.
  • 사용자 정의 함수와 내장 함수를 구분한다.
📖 개념 및 설명

함수(Function)는 특정 작업을 수행하는 코드 블록입니다. 같은 코드를 여러 번 쓰는 대신 함수로 묶어 두면, 재사용하고 프로그램을 모듈화하며 가독성을 높일 수 있습니다.

  • 사용자 정의 함수 — 내가 직접 def로 만든 함수
  • 내장 함수 — 파이썬이 기본 제공하는 함수(print, len, sum 등)

함수는 정의한 뒤 호출해야 실행됩니다.

def 함수이름(매개변수):
    함수의 내용        # 이 블록이 함수의 몸통 (4칸 들여쓰기)
매개변수(parameter) 함수가 작업에 사용할 입력값을 받는 변수입니다. 필요 없으면 ()를 비워 둡니다.
💡 예제

인사말을 출력하는, 반환값(return)이 없는 함수입니다.

def greet(name):        # 함수 정의
    print(f"{name}님, 환영합니다!")

greet("홍길동")             # 함수 호출
greet("김파이")             # 다시 재사용
실행 결과 홍길동님, 환영합니다! 김파이님, 환영합니다!
🤖 ChatGPT 활용

🤖 반복 코드를 함수로 묶어 달라고 하기

함수의 진짜 가치는 중복 제거입니다. 반복되는 코드를 붙여넣고 함수로 만들어 달라고 해 보세요.

파이썬 초보야. 아래처럼 비슷한 print가 반복되는 코드를, 이름을 매개변수로 받는 함수 하나로 묶어 줘. 왜 함수로 만드는 게 좋은지도 설명해 줘. print("홍길동님, 환영합니다!") print("김파이님, 환영합니다!") print("이순신님, 환영합니다!")

개념 비유가 필요할 때:

함수 정의(def)와 함수 호출의 차이를 '요리 레시피'와 '요리하기'에 비유해 초보자용으로 설명해 줘.
✏️ 실습문제

실습 1-1. 인사 함수 만들기

이름과 나이를 매개변수로 받아 "OOO님은 OO살입니다."를 출력하는 함수 info를 만들고, 서로 다른 값으로 두 번 호출하세요.
정답 보기
def info(name, age):
    print(f"{name}님은 {age}살입니다.")

info("홍길동", 20)
info("김파이", 25)
홍길동님은 20살입니다. 김파이님은 25살입니다.

실습 1-1을 스스로 작성한 뒤, 내 함수를 ChatGPT에 붙여넣고 “초보자 관점에서 개선할 점이 있는지” 리뷰를 요청하세요. AI가 제안한 방식(예: f-string)을 실제로 실행해 결과가 같은지 검증하세요.
예시 프롬프트 보기
파이썬 초보인데 아래 함수를 만들었어. 오류가 없는지, 더 읽기 좋게 개선할 점이 있는지 초보자 눈높이로 리뷰해 줘. 문자열을 합치는 더 쉬운 방법이 있으면 알려 줘. def info(name, age): print(name + "님은 " + str(age) + "살입니다.")

AI가 f"{name}님은 {age}살입니다."를 제안할 수 있습니다. 새 문법은 “그게 뭐야?”로 이어 물으며 확장 학습하세요.

2

return이 있는 함수

🎯 학습목표
  • return으로 함수의 결과값을 돌려줄 수 있다.
  • 반환값을 변수에 저장해 재사용할 수 있다.
  • 계산 결과를 돌려주는 함수를 설계할 수 있다.
📖 개념 및 설명

return은 함수가 계산한 결과값을 호출한 곳으로 돌려주는 명령입니다. print는 화면에 보여줄 뿐이지만, return한 값은 변수에 저장하거나 다른 계산에 다시 사용할 수 있습니다.

def 함수이름(매개변수):
    return 반환값     # 값을 돌려주고 함수를 끝냄
⚠️ print와 return의 차이 print는 그냥 보여주기만 하고, return은 값을 넘겨줍니다. total = add(3, 5)처럼 결과를 저장하려면 return이 필요합니다.
💡 예제 
def add(a, b):
    return a + b

result = add(3, 5)     # 반환값을 변수에 저장
print(result)          # 8

# 원의 넓이를 반환하는 함수
def circle_area(r):
    return 3.14 * r * r

print(circle_area(5))   # 78.5
실행 결과 8 78.5
🤖 ChatGPT 활용

🤖 "왜 None이 나오지?"를 AI에게

초보자는 return을 빼먹고 print만 해서 None 문제를 자주 겪습니다. 코드를 붙여넣으면 원인을 짚어 줍니다.

아래 파이썬 코드에서 result를 출력하니 None이 나와. 왜 그런지, 어떻게 고쳐야 하는지 print와 return의 차이와 함께 초보자용으로 설명해 줘. def add(a, b): print(a + b) result = add(3, 5) print(result)

가로·세로를 매개변수로 받아 넓이를 return하는 함수 rect_area를 만들고, 그 결과를 출력하세요.

실습 2-2. 절대값 함수

정수를 입력받아 절대값을 돌려주는 함수 my_abs를 만드세요. (10 → 10, −10 → 10) 내장 함수 abs는 쓰지 말고 직접 구현하세요.
정답 보기
def my_abs(n):
    if n < 0:
        return -n
    return n

print(my_abs(10))    # 10
print(my_abs(-10))   # 10
10 10

🤖 AI 실습 2-3. 내 함수 vs 내장 함수 검증

실습 2-2에서 만든 my_abs가 정말 내장 abs와 똑같이 동작하는지, ChatGPT에 “어떤 입력으로 테스트하면 좋을지” 물어 여러 값(0, 음수, 소수 등)으로 직접 검증하세요.
예시 프롬프트 · 검증 보기
내가 만든 절대값 함수 my_abs가 파이썬 내장 abs와 똑같이 동작하는지 확인하고 싶어. 어떤 입력값들로 테스트하면 좋을지 추천해 주고, 두 함수 결과를 비교하는 코드도 만들어 줘.
for n in [10, -10, 0, -3.5]:
    print(my_abs(n), abs(n))   # 두 값이 같아야 함

0과 음수 경계, 소수까지 넣어 보는 것이 좋은 테스트 습관입니다.

여러 값을 반환하는 함수

🎯 학습목표
  • 함수가 값을 여러 개 반환할 수 있음을 이해한다.
  • 반환된 여러 값을 변수 여러 개로 나눠 받을 수 있다.
  • 최소·최대처럼 두 결과를 한 번에 돌려줄 수 있다.
📖 개념 및 설명

파이썬은 return 뒤에 값을 쉼표로 나열하면 여러 값을 한 번에 돌려줍니다. 이때 값들은 튜플로 묶여 반환되며, 받는 쪽에서 변수 여러 개로 나눠 받을 수 있습니다.

return 값1, 값2       # 두 값을 함께 반환
a, b = 함수()          # 각각 나눠 받기
💡 예제 
def min_max(nums):
    return min(nums), max(nums)   # 두 값 반환

low, high = min_max([70, 80, 55, 90, 40])
print("최소:", low)
print("최대:", high)
실행 결과 최소: 40 최대: 90
🤖 ChatGPT 활용

🤖 튜플 언패킹, 그림처럼 이해하기

a, b = 함수()가 어떻게 두 값을 나눠 받는지 헷갈리면 AI에게 단계별 설명을 청하세요.

파이썬에서 return min(nums), max(nums) 처럼 두 값을 반환하고 low, high = min_max(...) 로 받을 때, 값이 어떻게 나뉘어 담기는지 단계별로 설명해 줘. 튜플이 왜 중간에 등장하는지도 알려 줘.

실습 3-1. 몫과 나머지 함수

두 수를 받아 몫과 나머지를 함께 반환하는 함수 div_mod를 만들고, 30과 4로 호출해 결과를 출력하세요.
정답 보기
def div_mod(a, b):
    return a // b, a % b

q, r = div_mod(30, 4)
print("몫:", q, "나머지:", r)
몫: 7 나머지: 2

🤖 AI 실습 3-2. 통계 함수 만들고 검산하기

숫자 리스트를 받아 합계·평균·최소·최대를 한 번에 반환하는 함수를 ChatGPT에 요청하세요. [70, 80, 55, 90, 40]로 실행한 뒤 각 값을 손으로 검산해 검증하세요.
정답·검산 보기
파이썬으로 숫자 리스트를 받아 합계, 평균, 최소값, 최대값을 한 번에 반환하는 함수 stats를 만들어 줘. 반환값을 여러 변수로 나눠 받는 예시도 함께 보여 줘.
def stats(nums):
    return sum(nums), sum(nums)/len(nums), min(nums), max(nums)

s, avg, lo, hi = stats([70, 80, 55, 90, 40])
print(s, avg, lo, hi)   # 335 67.0 40 90

검산: 합 70+80+55+90+40=335, 평균 335/5=67. AI 결과와 일치하는지 확인!

매개변수로 리스트 전달

🎯 학습목표
  • 리스트를 함수의 매개변수로 넘길 수 있다.
  • 함수 안에서 다른 함수를 호출할 수 있다.
  • 리스트를 순회해 최대값과 그 위치를 찾을 수 있다.
📖 개념 및 설명

함수의 매개변수로는 숫자·문자열뿐 아니라 리스트도 넘길 수 있습니다. 여러 개의 데이터를 한꺼번에 처리할 때 유용합니다. 함수 안에서 그 리스트를 순회하거나, 가공해 새 리스트를 만들어 반환할 수 있습니다.

함수 안에서 함수 호출 함수 내부에서 다른 함수(내장 함수 포함)를 불러 쓸 수 있어, 작은 함수를 조립해 큰 기능을 만듭니다.
💡 예제

리스트의 각 요소를 2배로 만든 새 리스트를 반환합니다.

def double_all(lst):
    result = []
    for x in lst:
        result.append(x * 2)
    return result

print(double_all([1, 2, 3]))   # [2, 4, 6]
실행 결과 [2, 4, 6]
✏️ 실습문제

실습 4-1. 최대값과 위치 찾기

숫자 리스트를 받아 최대값과 그 위치(인덱스)를 함께 반환하는 함수 find_max를 만드세요. 예: [70,80,55,60,90,40] → 최대값 90, 위치 4
정답 보기
def find_max(nums):
    max_v = nums[0]        # 첫 값을 최대값으로 가정
    max_i = 0
    for i in range(1, len(nums)):
        if nums[i] > max_v:  # 더 큰 값을 만나면 갱신
            max_v = nums[i]
            max_i = i
    return max_v, max_i

v, i = find_max([70, 80, 55, 60, 90, 40])
print("최대값:", v, "/ 위치:", i)
최대값: 90 / 위치: 4

변수의 유효 범위

🎯 학습목표
  • 전역 변수와 지역 변수의 유효 범위를 구분한다.
  • 함수 안에서 만든 변수가 함수 밖에서 사라짐을 이해한다.
  • global 키워드의 역할과 주의점을 안다.
📖 개념 및 설명

변수는 어디서 만들었는지에 따라 사용할 수 있는 범위(유효 범위, scope)가 정해집니다.

구분설명
전역 변수(global)함수 밖에서 선언. 프로그램 전체에서 읽을 수 있고, 끝나면 사라진다.
지역 변수(local)함수나 블록 안에서 생성. 그 블록을 벗어나면 사라진다.

함수 안에서 전역 변수의 값을 바꾸려면 global 키워드로 “이건 전역 변수야”라고 알려야 합니다. (지역 변수에 global을 붙이면 값이 유지되는 정적 변수처럼 동작)

⚠️ global 남용 주의 전역 변수를 함수마다 바꾸면 어디서 값이 변했는지 추적하기 어렵습니다. 되도록 매개변수와 return으로 값을 주고받는 것이 좋습니다.
💡 예제 
x = 10              # 전역 변수

def show():
    y = 5          # 지역 변수 (show 안에서만 유효)
    print(x, y)     # 전역 x는 읽을 수 있음

show()
# print(y)  → 오류! y는 함수 밖에서 사라짐

count = 0
def up():
    global count   # 전역 count를 수정하겠다고 선언
    count += 1

up()
up()
print(count)         # 2
실행 결과 10 5 2

실습 5-1. 배송비 계산 프로그램

상품 가격을 매개변수로 받아, 40000원 미만이면 배송비 3000원을 더한 총액을, 40000원 이상이면 가격 그대로를 반환하는 함수 total_price를 만드세요.
정답 보기
def total_price(price):
    if price < 40000:
        return price + 3000
    return price

print(total_price(30000))   # 33000
print(total_price(50000))   # 50000

기본 매개변수와 가변 매개변수

🎯 학습목표
  • 기본값을 가진 매개변수를 정의하고 생략 호출할 수 있다.
  • 개수가 정해지지 않은 인자를 *args로 받을 수 있다.
  • 상황에 맞는 매개변수 형태를 선택할 수 있다.
📖 개념 및 설명

기본 매개변수는 매개변수에 미리 기본값을 지정해 두는 것입니다. 호출할 때 값을 생략하면 기본값이 쓰입니다.

def 함수(변수1, 변수2=1):   # 변수2를 생략하면 1이 됨
    코드블록

가변 매개변수는 인자의 개수가 정해지지 않았을 때 씁니다. 이름 앞에 *를 붙이면 넘어온 값들이 튜플로 묶여 들어옵니다.

def 함수(*변수):        # 몇 개가 오든 튜플로 받음
    코드블록
💡 예제 
# 기본 매개변수: exp를 생략하면 제곱(2)
def power(base, exp=2):
    return base ** exp

print(power(3))       # 9  (3의 2제곱)
print(power(2, 3))    # 8  (2의 3제곱)

# 가변 매개변수: 개수 상관없이 합계
def total(*nums):
    return sum(nums)

print(total(1, 2, 3))       # 6
print(total(1, 2, 3, 4, 5)) # 15
실행 결과 9 8 6 15
🤖 ChatGPT 활용

🤖 *args와 **kwargs, 한 번에 정리받기

*args가 익숙해지면 **kwargs가 궁금해집니다. AI에게 둘을 예시로 비교해 달라고 하세요.

파이썬의 가변 매개변수 *args와 키워드 가변 매개변수 **kwargs의 차이를, 같은 함수에 둘 다 쓰는 짧은 예시와 함께 초보자용으로 설명해 줘.

7

내장 함수(Built-in Function)

🎯 학습목표
  • 자주 쓰는 파이썬 내장 함수를 활용할 수 있다.
  • sum·max·round·eval·list 등을 상황에 맞게 쓴다.
  • 직접 만든 함수와 내장 함수의 결과를 비교할 수 있다.
📖 개념 및 설명

내장 함수는 파이썬이 기본 제공하는, 따로 만들지 않아도 바로 쓰는 함수입니다. 자주 쓰는 것들을 알아 두면 코드가 훨씬 짧아집니다.

함수기능예 → 결과
sum(반복형)모든 요소의 합sum([1,2,3]) → 6
max(반복형)최대값 (min은 최소값)max([1,2,3]) → 3
len(반복형)요소 개수len("파이썬") → 3
round(n, 자리)반올림round(4.6) → 5
eval(문자열)문자열 수식을 계산eval("1+2") → 3
list(반복형)리스트로 변환list("py") → ['p','y']
💡 예제 
print(sum([1, 2, 3]))     # 6
print(max([1, 2, 3]))     # 3
print(round(4.6))         # 5
print(eval("1+2"))         # 3
print(list("python"))     # ['p','y','t','h','o','n']
실행 결과 6 3 5 3 ['p', 'y', 't', 'h', 'o', 'n']
🤖 ChatGPT 활용

🤖 "이 작업에 맞는 내장 함수 있어?"

직접 for문으로 짜기 전에, 이미 있는 내장 함수를 물어보면 코드가 짧아집니다.

파이썬에서 리스트를 정렬하거나, 요소별 인덱스와 값을 함께 순회하거나, 참인 요소가 하나라도 있는지 확인할 때 쓸 수 있는 내장 함수를 알려 주고, 각각 짧은 예시를 보여 줘.
예시 답변 보기

위에서 질문한 세 가지 상황에 각각 이런 내장 함수를 씁니다.

정렬은 sorted() — 원본은 그대로 두고 정렬된 새 리스트를 돌려줍니다.

print(sorted([3, 1, 2]))              # [1, 2, 3]
print(sorted([3, 1, 2], reverse=True))  # [3, 2, 1]

인덱스와 값을 함께 순회할 때는 enumerate().

for i, name in enumerate(["사과", "바나나", "체리"]):
    print(i, name)
# 0 사과 / 1 바나나 / 2 체리

참인 요소가 하나라도 있는지는 any() (모두 참인지는 all()).

print(any([0, 0, 85]))  # True
print(all([0, 0, 85]))  # False

실습 7-1. 합계 함수 만들고 내장 함수와 비교

1부터 n까지의 합을, ① for(또는 sum(range))로 직접 계산하는 함수와 ② 공식 n×(n+1)÷2로 계산하는 함수를 만들어, n=100일 때 결과가 같은지 확인하세요.
정답 보기
def sum1(n):
    return sum(range(1, n + 1))   # 방법 1

def sum2(n):
    return n * (n + 1) // 2       # 방법 2 (공식)

print(sum1(100), sum2(100))    # 5050 5050

람다 함수와 map · filter

🎯 학습목표
  • 람다(익명) 함수의 개념과 문법을 이해한다.
  • map으로 모든 요소에 연산을 적용할 수 있다.
  • filter로 조건에 맞는 요소만 뽑을 수 있다.
📖 개념 및 설명

람다 함수(Lambda)는 이름이 없는 한 줄짜리 함수입니다. def 없이 간단한 함수를 즉석에서 만들 때 씁니다. return을 쓰지 않고 표현식의 결과가 곧 반환값입니다.

lambda 매개변수: 반환할 표현식

람다는 map, filter와 자주 함께 씁니다.

함수기능
map(함수, 순서열)모든 요소에 함수를 적용한 결과
filter(함수, 순서열)함수가 참인 요소만 골라냄
list()로 감싸기 map·filter의 결과는 바로 보이지 않으므로, list()로 감싸 리스트로 변환해 확인합니다.
💡 예제 
# 람다: 제곱 함수
square = lambda x: x * x
print(square(5))        # 25

# map: 모든 요소를 2배로
print(list(map(lambda x: x * 2, [1, 2, 3])))

# filter: 짝수만 추출
print(list(filter(lambda x: x % 2 == 0, range(1, 11))))
실행 결과 25 [2, 4, 6] [2, 4, 6, 8, 10]
🤖 ChatGPT 활용

🤖 "람다는 언제 쓰나요?"

람다는 문법은 간단하지만 언제 쓰는지가 헷갈립니다. def 함수와 비교해 달라고 하세요.

파이썬 람다 함수와 def로 만든 함수를 같은 예제로 비교해 주고, 언제 람다를 쓰는 게 좋고 언제 def가 나은지 초보자용으로 정리해 줘.

세 가지 표현을 연결해 이해하고 싶을 때:

같은 '짝수만 뽑기' 작업을 (1) for문 (2) 리스트 내포 (3) filter+람다 세 가지로 각각 보여 주고, 초보자가 이해하기 쉬운 순서로 설명해 줘.
